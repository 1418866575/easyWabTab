    初阶 · 家长课堂
    已知 333³ + 444³ + 555³ = a³，则 a = ?
    解：(111×3)³ + (111×4)³ + (111×5)³ = a³
    111³×3³ + 111³×4³ + 111³×5³ = a³
    111³×(3³ + 4³ + 5³) = a³
    111³×216 = a³　（其中 3³+4³+5³=27+64+125=216）
    111³×6³ = a³
    666³ = a³
    ∴ a = 666
    初阶 · 家长课堂
    已知 x = 41−x，求 x。
    解：两边同构，考虑指数方程 xa = ax ⟹ x = a 或对称情形。
    取对数得 x = 41/x，化为 x/4 = 4x …

    解得 x = 2（另可验证对称解）。

    四、一元二次方程

    一般形式：ax² + bx + c = 0　(a ≠ 0)

    1. 求根公式：x1,2 = −b ± √b²−4ac2a　(b²−4ac ≥ 0)
    2. 根的判别式：Δ = b² − 4ac
      当 Δ > 0 时，有两个不相等实数根；
      当 Δ = 0 时，有两个相等实数根；
      当 Δ < 0 时，没有实数根。
    3. 根与系数的关系（韦达定理）：x₁ + x₂ = −b/a，x₁·x₂ = c/a
      逆定理：若 x₁+x₂=m，x₁x₂=n，则以 x₁,x₂ 为根的方程是 x² − mx + n = 0。
    4. 常用等式：x₁²+x₂² = (x₁+x₂)² − 2x₁x₂；(x₁−x₂)² = (x₁+x₂)² − 4x₁x₂
    5. 不解方程求对称式：
      ① x₁²+x₂² = (x₁+x₂)² − 2x₁x₂　② 1x₁ + 1x₂ = x₁+x₂x₁x₂

    知识概念 1. 有理数

    (1) 凡能写成 q/p（p、q 为整数且 p≠0）形式的数，都是有理数；正整数、0、负整数统称整数；正分数、负分数统称分数；整数和分数统称有理数。

    注意：0 既不是正数，也不是负数；−a 不一定是负数，+a 也不一定是正数；π 不是有理数。

    (2) 有理数的分类（两种分法）：

    ① 按符号分：有理数 → 正有理数（正整数、正分数）／ 零 ／ 负有理数（负整数、负分数）

    ② 按形式分：有理数 → 整数（正整数、零、负整数）／ 分数（正分数、负分数）

    2–5 数轴 · 相反数 · 绝对值 · 比大小

    2. 数轴：规定了原点、正方向、单位长度的一条直线。

    3. 相反数：(1) 只有符号不同的两个数互为相反数；0 的相反数还是 0。(2) 相反数的和为 0 ⇔ a+b=0 ⇔ a、b 互为相反数。

    4. 绝对值：(1) 正数的绝对值是它本身，0 的绝对值是 0，负数的绝对值是它的相反数；绝对值是数轴上表示某数的点离开原点的距离。(2) 表示：

    {a   (a>0)
    0   (a=0)
    −a  (a<0)

    绝对值的问题经常要分类讨论。

    5. 有理数比大小：(1) 正数的绝对值越大，这个数越大；(2) 正数永远比 0 大，负数永远比 0 小；(3) 正数大于一切负数；(4) 两个负数比大小，绝对值大的反而小；(5) 数轴上右边的数总比左边的大；(6) 大数−小数>0，小数−大数<0。

    6–10 倒数 · 加减乘 法则

    6. 互为倒数：乘积为 1 的两个数互为倒数。

    ★注意：① 0 没有倒数；② 若 a≠0，a 的倒数是 1/a；③ ab=1 ⟺ a、b 互为倒数；④ ab=−1 ⟺ a、b 互为负倒数。

    7. 有理数加法法则：(1) 同号两数相加，取相同的符号，并把绝对值相加；(2) 异号两数相加，取绝对值较大的符号，并用较大的绝对值减去较小的绝对值；(3) 一个数与 0 相加，仍得这个数。

    8. 加法运算律：(1) 交换律 a+b=b+a；(2) 结合律 (a+b)+c=a+(b+c)。

    9. 减法法则：减去一个数，等于加上这个数的相反数，即 a−b=a+(−b)。

    10. 乘法法则：(1) 两数相乘，同号得正，异号为负，并把绝对值相乘；(2) 任何数同 0 相乘都得 0；(3) 几个数相乘，有一个因数为 0，积为 0；若各因式都不为 0，积的符号由负因数的个数决定。

    11–17 运算律 · 除法 · 乘方 · 科学记数法 · 有效数字

    11. 乘法运算律：(1) 交换律 ab=ba；(2) 结合律 (ab)c=a(bc)；(3) 分配律 a(b+c)=ab+ac。

    12. 除法法则：除以一个数等于乘以这个数的倒数。

    注意：零不能做除数，即 a÷0 无意义。

    13. 乘方法则：(1) 正数的任何次幂都是正数；(2) 负数的奇次幂是负数，偶次幂是正数。

    注意：当 n 为正奇数时 (−a)n=−an 或 (a−b)n=−(b−a)n；当 n 为正偶数时 (−a)n=an 或 (a−b)n=(b−a)n。

    14. 乘方的定义：(1) 求相同因式的积的运算，叫做乘方；(2) 相同因式叫做底数，相同因式的个数叫做指数，乘方的结果叫做幂。

    15. 科学记数法：把一个大于 10 的数记成 a×10n 的形式，其中 a 是整数数位只有一位的数。

    16. 近似数的精确位：一个近似数，四舍五入到哪一位，就说这个近似数精确到哪一位。

    17. 有效数字：从左边第一个不为零的数字起，到精确的位数止，所有的数字，都叫这个近似数的有效数字。

    18 混合运算法则 · 章末总结

    18. 混合运算法则：先乘方，后乘除，最后加减。

    中考 "有理数"考点例析

    "有理数"是中学数学最基础的知识，在中考中占有一定比例，且是必考内容。主要考点有以下几种类型：

    考点一  考查正、负数的意义

    例1如果水位下降 3m 记作 −3m，那么水位上升 4m 记作（　）A. 1m　B. 7m　C. 4m　D. −7m
    解析：考查具有相反意义的量，应选 C。个别同学易同有理数加法相混而误选 A。

    考点二  考查有理数加减的意义

    例2已知甲地海拔 300m，乙地海拔 −50m，那么甲地比乙地高多少 m？
    解析：由有理数减法的意义，甲比乙高 300 − (−50) = 350（m）。

    考点三  考查基本概念

    例3已知 a、b 互为相反数，c、d 互为倒数，x 的绝对值等于 1，求 a+b+x²−cdx 的值。
    解析：由已知 a+b=0，cd=1，又 |x|=1 知 x=±1。
    当 x=1 时，原式 = 0+1²−1×1 = 0；
    当 x=−1 时，原式 = 0+(−1)²−1×(−1) = 2。
    ∴ 原式的值为 0 或 2。
    例4已知 P 与 3q 互为相反数，且 P≠0，那么 P 的倒数是（　）A. 3q　B. −(1/3q)　C. 3q　D. −3q
    解析：由 P+3q=0 得 P=−3q，故 P 的倒数为 −1/(3q)，应选 B。

    考点四  考查有理数大小的比较方法

    例5下表是我国四个城市某日平均气温，请按从低到高排列：北京 −7.6℃、乌鲁木齐 −20.8℃、上海 0.5℃、广州 12.7℃。
    解析：两个负数比较，绝对值大的反而小；由 |−20.8|>|−7.6| 得排列为 −20.8℃ < −7.6℃ < 0.5℃ < 12.7℃。✓
    例6在 1、−1、−2 三个数中任意两数之和的最大值是（　）A. 1　B. 0　C. −1　D. −3
    解析：任意两数之和有 1+(−1)=0、1+(−2)=−1、(−1)+(−2)=−3，最大为 0，选 B。

    考点五  考查科学记数法、近似数

    例7三峡工程年内可发电 5500000000 度，用科学记数法表示为 ____ 度；近似数 0.30 精确到 ___ 位，有 ___ 个有效数字。
    解析：5500000000 = 5.5×109；0.30 精确到百分位（即 0.01），有 2 个有效数字。

    考点六  考查有理数的运算

    例8(1) 计算 −9+5×(−6)−(−4)²÷(−8)；(2) 计算 (−1)5 − [−3×(−½)² − 1⅓ ÷ (−2)²]。
    解析：注意运算顺序：先乘方，再乘除，最后加减，有括号先算括号内。
    (1) 原式 = −9 + 5×(−6) − 16 ÷ (−8) = −9 − 30 + 2 = −37。
    (2) 原式 = −1 − [−3×¼ − (4/3)÷4] = −1 − [−3/4 − 1/3] = −1 − (−13/12) = −1 + 13/12 = 1/12。

    考点七  考查非负数的性质

    例9若有理数 a、b 满足 |3a−1| + (b−2)² = 0，则 ab 的值为 ____。

    十、手写笔记 · 二元一次方程组

    No. ____   Date ____

    七年级数学（下）第八章。掌握二元一次方程（组）的概念，熟练运用代入消元法与加减消元法求解，并能列方程组解决实际问题。

    第四章 二元一次方程组 · 知识概念

    1. 二元一次方程：含有两个未知数，并且未知数的指数都是 1，像这样的方程叫做二元一次方程。一般形式是 ax+by=c（a≠0 , b≠0）。

    2. 二元一次方程组：把两个二元一次方程合在一起，就组成了一个二元一次方程组。

    3. 二元一次方程的解：一般地，使二元一次方程两边的值相等的未知数的值，叫做这个二元一次方程的解。

    4. 二元一次方程组的解：一般地，二元一次方程组的两个方程的公共解，叫做这个二元一次方程组的解。

    5. 消元：将未知数的个数由多化少、逐一解决的想法，叫做消元思想。

    6. 代入消元：将一个未知数用含有另一个未知数的式子表示出来，再代入另一个方程，实现消元进而求得方程组的解，这种方法叫做代入消元法，简称代入法。

    7. 加减消元法：当两个方程中同一未知数的系数相反或相等时，将两个方程两边分别相加或相减，就能消去这个未知数，这种方法叫做加减消元法，简称加减法。

    小结 重点与难点

    重点：二元一次方程组的解法，列二元一次方程组解决实际问题。

    难点：列二元一次方程组解决实际问题。

    解题技巧 代入消元法
    例解方程组 x+y=5 ① ， 6x+13y=89 ② 。
    解：由①得 x=5−y ③ ；把③代入②得 6(5−y)+13y=89 ， y=59/7 ；把 y=59/7 代入③， x=5−59/7=−24/7 。
    ∴ x=−24/7 ， y=59/7 为方程组的解。✓

    这种通过"代入"消去一个未知数，从而求出方程组解的方法，叫做代入消元法。

    解题技巧 加减消元法
    例解方程组 x+y=9 ① ， x−y=5 ② 。
    解：①＋② 得 2x=14 ，即 x=7 ；把 x=7 代入①得 7+y=9 ， y=2 。
    ∴ x=7 ， y=−2 为方程组的解。✓

    像这种解二元一次方程组的方法叫做加减消元法，简称加减法。

    重点剖析 方程组的解有三种情况

    1. 有一组解：如方程组 { x+y=5 ; 6x+13y=89 } ，解得 x=−24/7 , y=59/7 。

    2. 有无数组解：如方程组 { x+y=6 ; 2x+2y=12 } ，两方程实为同一个方程，故有无数组解。

    3. 无解：如方程组 { x+y=4 ; 2x+2y=16 } ，②化简后为 x+y=8 ，与①矛盾，故无解。

    注意：用加减法或代入消元法时，应注意用哪种方法简单，避免计算麻烦或导致计算错误。✓
    拓展 教科书中没有的几种解法

    （一）加减—代入混合使用

    例113x+14y=41 (1) ， 14x+13y=40 (2) 。
    解：(2)－(1) 得 x−y=−1 ，即 x=y−1 (3) ；把③代入①， 13(y−1)+14y=41 ⇒ 27y=54 ⇒ y=2 ；代入得 x=1 。
    ∴ x=1 , y=2 。✓

    特点：两方程相减成单个 x 或单个 y ，就适用接下来的代入消元。

    （二）换元法

    例2(x+5)+(y−4)=8 ， (x+5)−(y−4)=4 。
    解：令 x+5=m ， y−4=n ，则 m+n=8 ， m−n=4 ⇒ m=6 , n=2 ；于是 x+5=6 ， y−4=2 ⇒ x=1 , y=6 。✓

    特点：两方程都含有相同的代数式（如 x+5 、 y−4 ），换元后可简化方程。

    （三）另类换元（比例）

    例3x : y = 1 : 4 ，且 5x+6y=29 。
    解：由比例设 x=t , y=4t ，代入 5t+6·4t=29 ⇒ 29t=29 ⇒ t=1 ⇒ x=1 , y=4 。✓
    注意：二元一次方程组不一定都是由两个二元一次方程合在一起组成的，也可以由一个或多个二元一次方程单独组成。
    总结：一般来说，二元一次方程组只有唯一的一个解（除非出现无数解或无解的特殊情形）。
    中考题型 例析

    题型一　方程组解的判定

    例1已知二元一次方程组 { 2x+y=2 ; −x+y=5 } 的解是（　） A. {x=1,y=6}　B. {x=−1,y=4}　C. {x=−3,y=2}　D. {x=3,y=2}
    解：法一解方程组，法二将选项代入验证；得 x=−1 , y=4 ，选 B。

    题型二　求待定系数或代数式的值

    例2已知 { ax+by=4 ; bx+ay=5 } 的解是 { x=2 ; y=1 } ，则 a+b 的值为____。
    解：代入方程组得 { 2a+b=4 ; 2b+a=5 } ；两式相加 3(a+b)=9 ⇒ a+b=3 。✓
    评注：运用整体思想巧求代数式的值是中考常考内容，解题时注意观察方程组特点，灵活变形。

    题型三　解方程组

    例3解方程组 { 3x+2y=5 ; 2x−y=8 } 。

    ∴ 方程组的解为 x=3 , y=−2 。✓

    第九章 不等式与不等式组 · 知识概念

    1. 不等式：用符号 < > ≤ ≥ 表示大小关系的式子，叫做不等式。

    2. 不等式的解：使不等式成立的未知数的值，叫做不等式的解。

    3. 不等式的解集：一个含有未知数的不等式的所有解，组成这个不等式的解集。

    4. 一元一次不等式：左、右两边都是整式，只有一个未知数，且未知数的最高次数是 1，像这样的不等式，叫做一元一次不等式。

    5. 一元一次不等式组：一般地，关于同一未知数的几个一元一次不等式合在一起，就组成了一个一元一次不等式组。

    6. 不等式的性质（红点重点）：

    · 性质 1：不等式两边都加上（或减去）同一个数（或式子），不等号方向不变。

    · 性质 2：不等式两边都乘以（或除以）同一个正数，不等号方向不变。

    · 性质 3：不等式两边都乘以（或除以）同一个负数，不等号方向改变。

    重点剖析 中考知识梳理

    1. 判断不等式是否成立：关键是分析不等号的变法，依据是不等式的性质。特别注意：两边同乘（或除以）同一个负数时，要改变不等号方向；反之，若不等号方向改变，说明两边同乘（或除以）了一个负数。

    2. 解一元一次不等式（组）：步骤与解一元一次方程大致相同，应注意乘除的数的正负。不等式组解集确定（设 a<b ）：

    · { x<a ; x<b } → x<a　"小取小"

    · { x>a ; x>b } → x>b　"大大取大"

    · { x>a ; x<b } → a<x<b　"大小小大取中间"

    · { x<a ; x>b } → 空集　"大大小小取不了"

    常与分式、根式、方程、函数等知识联系，解决综合性问题。

    3. 求不等式（组）的特殊解：整数解、非负整数解等，先确定解集，再找相应答案，注意数形结合思想。

    提示：不等式（组）的解往往有无数个，但其特殊解在某些范围内是有限的。✓

    例1如图，数轴上两点 A、B 表示的数分别为 a、b，则下列结论正确的是（　） A. 3b−a>0　B. a−b>0　C. 2a+b>0　D. a+b>0

    No. ____   Date ____

    第六章 数据的收集、整理与描述 · 知识概念

    1. 全面调查：考察全体对象的调查方式。

    2. 抽样调查：调查部分数据，根据部分来估计总体的调查方式。

    3. 总体：要考察的全体对象。

    4. 个体：组成总体的每一个考察对象。

    5. 样本：被抽取的所有个体组成一个样本。

    6. 样本容量：样本中个体的数目。

    7. 频数：落在不同小组中的数据个数。

    8. 频率：频数与数据总数的比。

    9. 组数和组距：把数据按一定范围分成若干组，分成的组数称组数，每组两端点之差称组距。

    要点梳理 总体 · 样本 · 调查方式

    总体 / 个体 / 样本 / 样本容量：要考察的全体对象称为总体；组成总体的每一个考察对象称为个体；被抽取的那些个体组成样本；样本中个体的数目叫样本容量（不带单位）。

    注意：为使样本较好地反映总体，除有合适的样本容量外，抽取时尽量使每个个体有同等机会被抽到。✓

    全面调查（普查）：考察全体对象，要求逐个准确统计。步骤：① 收集数据；② 整理数据（划记法）；③ 描述数据（条形图或扇形图等）。

    抽样调查：因考察对象多、面广，不宜全面调查时，抽取一部分对象调查，再推断全体。意义：① 减少统计工作量；② 实际应用广泛。

    判断方法：① 全面调查对范围内所有个体逐个统计；抽样调查对部分个体调查，以样本估计总体。② 既要考虑解决问题本身的需要，又要考虑实现的可能性和所付出代价的大小。
    统计图 扇形图 · 条形图

    扇形统计图：用圆代表总体，各扇形代表不同部分，大小反映部分占总体的百分比。

    · 优点：用面积表示部分占总体的百分比，易于表示每组数据相当于总体的百分比；各部分百分比之和为 100% 或 1 。

    · 圆心角计算：圆心角的度数 = 百分比 × 360°（如 36°→10%，72°→20%）。

    · 缺点：在不知总体数量时，无法知道每组数据的具体数量。

    条形统计图：用等宽长短不同的条形表示数量多少。

    · 优点：能显示每组中的具体数据，易于比较数据之间的差别；缺点是无法显示每组数据占总体的百分比。

    注意：纵轴一般从 0 开始，也可不从 0 以突出差别；分纵置和横置两种。
    频数频率 分布表 · 直方图

    频数：落在不同小组中的数据个数；频率：频数与数据总数的比值。

    · 公式：频率 = 频数 ÷ 数据总数

    · 变形：频数 = 频率 × 数据总数；数据总数 = 频数 ÷ 频率

    注意：① 所有频数之和一定等于总数；② 所有频率之和一定等于 1 。✓

    频数分布直方图：横轴表示数据范围，纵轴表示频数，以频数为高画矩形。

    No. ____   Date ____

    八年级数学（上）第一章。全等三角形是研究图形关系的基础，核心是五种判定（SAS、ASA、SSS、AAS、HL）与常见辅助线构造法。

    第一章 全等三角形 · 知识概念

    1. 全等三角形：两个三角形形状、大小都一样，其中一个可经平移、旋转、对称等变换与另一个重合，这两个三角形称为全等三角形。

    2. 性质：对应角相等，对应边相等。

    3. 判定及推论：① SAS（边角边）；② ASA（角边角）；③ SSS（边边边）；④ AAS（角角边）；⑤ HL（斜边和直角边相等的两直角三角形）。注意：边边角（SSA）、角角角（AAA）不能判定全等。

    4. 角平分线推论：角的内部到角两边距离相等的点，在角的平分线上。

    5. 证明全等的基本步骤：① 确定已知条件（含隐含条件：公共边、公共角、对顶角、角平分线、中线、高、等腰三角形等）；② 回顾判定，弄清还缺什么；③ 正确书写证明格式（顺序与对应关系从已知推出结论）。

    复习 证明全等的思路

    已知两边：找夹角 → SAS；找第三边 → SSS；找直角 → HL。

    已知一边一角：边为角的对边 → 找任一角 → AAS；边为角的邻边 → 找夹角另一边 → SAS，或找夹边另一角 → ASA，或找边的对角 → AAS。

    已知两角：找夹边 → ASA；找任一对边 → AAS。

    切记："有三个角对应相等"和"有两边及其中一边的对角对应相等"的两个三角形不一定全等。✓
    典例 例1 · 旋转构造
    例1A、F、E、B 共线，AC⊥CE，BD⊥DF，AE=BF，AC=BD。求证：△ACF≌△BDE。
    证明：由 AC⊥CE，BD⊥DF 得 ∠ACE=∠BDF=90° ；在 Rt△ACE 与 Rt△BDF 中 { AE=BF ; AC=BD } ，∴ Rt△ACE≌Rt△BDF（HL），得 ∠A=∠B ；又 AE=BF ⇒ AF=BE ；在 △ACF 与 △BDE 中 { AF=BE ; ∠A=∠B ; AC=BD } ，∴ △ACF≌△BDE（SAS）。✓
    思路（两头凑）：一方面从结论看还需什么条件，另一方面从条件看能推出什么，对比二者是否吻合。
    典例 例2 · 旋转观点
    例2△ABC 中 AB=BC，∠ABC=90°，F 为 AB 延长线上一点，E 在 BC 上且 BE=BF。连接 AE、EF、CF。求证：AE=CF。
    证明：∠ABC=90° 且 F 在 AB 延长线上，故 ∠ABC=∠CBF=90° ；在 △ABE 与 △CBF 中 { AB=BC ; ∠ABC=∠CBF ; BE=BF } ，∴ △ABE≌△CBF（SAS），∴ AE=CF 。✓
    评注：利用旋转的观点有利于寻找全等三角形及对应边角；必要时用平移、翻折、旋转等变换构造全等。
    辅助线 连对角线 · 作垂线
    例3AB∥CD，AD∥BC。求证：AB=CD。
    证明：连接 AC；由平行得 ∠1=∠2 , ∠3=∠4 ；在 △ABC 与 △CDA 中 { ∠1=∠2 ; AC=CA ; ∠4=∠3 } ，∴ △ABC≌△CDA（ASA），∴ AB=CD 。✓
    总结：连接四边形的对角线，是把四边形问题转化为全等三角形的常用方法。
    例5AP、CP 分别是 △ABC 外角 ∠MAC、∠NCA 的平分线，交于点 P。求证：BP 为 ∠MBN 的平分线。
    证明：过 P 作 PD⊥BM 于 D，PE⊥AC 于 E，PF⊥BN 于 F；由 AP 平分 ∠MAC 得 PD=PE ，由 CP 平分 ∠NCA 得 PE=PF ，故 PD=PF ；又 PD⊥BM、PF⊥BN，∴ BP 为 ∠MBN 的平分线。✓
    总结：已知含角平分线条件或需证角平分线结论时，常过角平分线上一点向两边作垂线，利用角平分线性质或判定解题。
    辅助线 倍长中线
    例6D 是 △ABC 边 BC 上的点，CD=AB，∠ADB=∠BAD，AE 是 △ABD 的中线。求证：AC=2AE。
    证明：延长 AE 至 F 使 EF=AE ，连接 DF；在 △ABE 与 △FDE 中 { AE=FE ; ∠AEB=∠FED ; BE=DE } ，∴ △ABE≌△FDE（SAS），得 ∠B=∠EDF 且 AB=DF ；由 ∠ADB=∠BAD 推得 ∠ADF=∠ADC ；又 AB=CD ⇒ DF=DC ，在 △ADF 与 △ADC 中 { AD=AD ; ∠ADF=∠ADC ; DF=DC } ，∴ △ADF≌△ADC（SAS），得 AF=AC ；而 AF=2AE ，故 AC=2AE 。✓
    总结：三角形中倍长中线，可构造全等三角形，得出线段相等，甚至证明两直线平行。
    辅助线 截长补短
    例7△ABC 中 AB＞AC，∠1=∠2，P 为 AD 上任意一点。求证：AB−AC＞PB−PC。
    证（截长法）：在 AB 上截取 AN=AC ，连接 PN；在 △APN 与 △APC 中 { AN=AC ; ∠1=∠2 ; AP=AP } ，∴ △APN≌△APC（SAS），得 PN=PC ；在 △BPN 中 PB−PN < BN ，即 PB−PC < AB−AC ，故 AB−AC > PB−PC 。✓
    证（补短法）：延长 AC 至 M 使 AM=AB ，连接 PM；在 △ABP 与 △AMP 中 { AB=AM ; ∠1=∠2 ; AP=AP } ，∴ △ABP≌△AMP（SAS），得 PB=PM ；在 △PCM 中 CM > PM−PC ，即 AB−AC > PB−PC 。
    总结：当已知或求证涉及线段的和或差时，一般用截长补短法——在较长线段上截取一段等于短线段（截长），或将短线段延长等于另一短线段（补短），再证其相等。不仅要记作法，更要理解为什么这样作。
    提分技巧：当题设条件及图形无明显全等条件时，应认真观察、挖掘潜在因素，通过添加适当辅助线巧妙构造全等三角形，借助其性质迅速找到证题途径。

    第二章 轴对称 · 知识概念

    1. 对称轴：图形沿某直线折叠后两旁部分重合，该图形叫轴对称图形，这条直线叫对称轴。

    2. 性质：① 对称轴是一对对应点所连线段的垂直平分线；② 角平分线上点到角两边距离相等；③ 线段垂直平分线上任一点到两端距离相等；④ 与线段两端距离相等的点，在这条线段的垂直平分线上；⑤ 轴对称图形上对应线段、对应角相等。

    3. 等腰三角形性质：两底角相等（等边对等角）。

    4. 三线合一：等腰三角形顶角平分线、底边上的高、底边上的中线互相重合。

    5. 等腰三角形判定：等角对等边。

    6. 等边三角形：三个内角相等，都等于 60° ；有一个角是 60° 的等腰三角形、或有两个角是 60° 的三角形，都是等边三角形。

    7. 直角三角形性质：30° 角所对的直角边等于斜边的一半；斜边上的中线等于斜边的一半。

    复习 轴对称与轴对称图形

    概念区分：轴对称图形指"一个图形"；轴对称指"两个图形"的位置关系。二者可互相转换：把成轴对称的两个图形看成一个整体→轴对称图形；把轴对称图形沿对称轴分成两个图形→关于该轴对称。

    线段垂直平分线（中垂线）：经过线段中点且垂直于该线段的直线。中垂线上的点到两端距离相等；到两端距离相等的点在中垂线上。

    第三章 实数 · 分类与概念

    实数的分类：实数分为有理数（整数、分数）与无理数（无限不循环小数，含正、负无理数）。

    算术平方根：正数 x 满足 x²=a 时，x 叫做 a 的算术平方根，记作 √a；0 的算术平方根是 0；仅当 a≥0 时 a 才有算术平方根。

    平方根：x²=a 时，x 叫做 a 的平方根。正数有两个平方根（一正一负，互为相反数）；0 的平方根是 0；负数没有平方根。

    立方根：正数的立方根为正；0 的立方根是 0；负数的立方根为负。

    相反数与绝对值：数 a 的相反数是 −a；正数的绝对值是它本身，负数的绝对值是它的相反数，0 的绝对值是 0。

    二次根式运算法则：√a·√b = √(ab)（a≥0,b≥0）；√(a/b) = √a/√b（a≥0,b>0）。

    重点一 概念识别

    变式2以数轴的单位线段为边作正方形，以原点为圆心、对角线为半径画弧交正半轴于 A，则 A 表示的数是（　） A.1.4　B. √2　C. √3
    解：正方形边长为 1，对角线为 √2，故 |AO|=√2，A 表示 √2，选 B。

    解：由 9<3π<10 得 3π−9>0 , 3π−10<0 ，原式 = (3π−9) − (3π−10) = 1 。

    描点法三步：① 列表；② 描点；③ 连线（按横坐标由小到大用平滑曲线连接）。

    表示方法：列表法、解析式法、图像法。

    第四章 一次函数 · 定义与性质

    一次函数：形如 y=kx+b（k、b 为常数，k≠0）的函数叫一次函数；当 b=0 时 y=kx 叫正比例函数。

    正比例函数 y=kx（k≠0）：经过 (0,0)、(1,k) ；k>0 过一、三象限，y 随 x 增大而增大；k<0 过二、四象限，y 随 x 增大而减小；|k| 越大越接近 y 轴。

    平移关系：y=kx+b 的图像由 y=kx 平移 |b| 个单位得到（b>0 上移，b<0 下移）。

    两直线位置关系（k≠0）：平行 ⇔ k₁=k₂且b₁≠b₂；相交 ⇔ k₁≠k₂；重合 ⇔ k₁=k₂且b₁=b₂；垂直 ⇔ k₁k₂=−1。

    待定系数法：① 设函数式含待定系数；② 代入已知点坐标得方程；③ 解方程求系数；④ 代回得解析式。

    典例 例析
    例1正比例函数 y=k₁x 与一次函数 y=k₂x−9 交于 P(3,−6)，求 k₁、k₂；若一次函数与 x 轴交于 A，求 A 坐标。
    解：代入 (3,−6)：k₁=−6/3=−2，−6=3k₂−9 ⇒ k₂=1 ；一次函数 y=x−9 与 x 轴交点令 y=0 ⇒ x=9 ，故 A(9,0) 。✓
    例2函数 y=kx+b 过点 A(4,3) 且与 y=x+1 平行，点 B(2,m) 也在其上。(1) 求解析式与 m；(2) x 轴上动点 P(x,0) 到 A(4,3)、B(2,m) 的 PA+PB 最小时，求 P 的横坐标。
    解：(1) 平行 ⇒ k=1，代入 A(4,3) 得 b=−1，解析式 y=x−1；B(2,m) 代入得 m=1 。(2) A(4,3)、B(2,1) 共线时 PA+PB 最小；AB 斜率 (1−3)/(2−4)=1，方程 y=x−1，令 y=0 ⇒ x=1 。✓
    例3一次函数过 B(−3,4) 且与 y 轴交于 A，OA=OB，求解析式。
    解：OB=5，故 A(0,5) 或 A(0,−5)。若 A(0,5)，代入 B(−3,4)：4=−3k+5 ⇒ k=1/3，y=x/3+5；若 A(0,−5)，4=−3k−5 ⇒ k=−3，y=−3x−5。✓

    第五章 幂的运算 · 整式乘法

    1. 同底数幂相乘：aᵐ·aⁿ = aᵐ⁺ⁿ（m,n 为正整数）。

    2. 幂的乘方：(aᵐ)ⁿ = aᵐⁿ；(−a)ⁿ = aⁿ（n 偶），= −aⁿ（n 奇）。

    3. 整式乘法：单项式×单项式（系数、同底数幂分别相乘，只在一个单项式里的字母连同指数作因式）；单项式×多项式（分配律）；多项式×多项式（每一项乘每一项再相加）。

    4. 平方差公式：(a+b)(a−b) = a²−b²。

    5. 完全平方公式：(a±b)² = a² ± 2ab + b²。

    6. 同底数幂相除：aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a≠0，m,n 为正且 m>n）。前提：同底数幂相除且 a≠0。

    进阶 零指数 · 负指数 · 整式除法

    ③ 零次幂：a⁰ = 1（a≠0）；0⁰ 无意义。

    ⑤ 负 p 次幂：a⁻ᵖ = 1/aᵖ（a≠0，p 正整数）；0⁻¹,0⁻² 无意义。a>0 时 a⁻ᵖ>0；a<0 时可能正也可能负，如 (−2)⁻²=1/4，(−2)⁻³=−1/8。

    7. 整式除法：单项式÷单项式（系数、同底数幂分别相除，只在被除式里的字母连同指数作商因式）；多项式÷单项式（每一项除以单项式再相加）。

    分解 因式分解

    8. 分解因式：把一个多项式化成几个整式的积的形式。结果必须是乘积，且分解到每个因式在有理数范围内不能再分为止。

    一般方法：① 提公因式法；② 运用公式法；③ 十字相乘法；④ 分组分解法。

    步骤：先看公因式→再试公式→再分组分解→结果须为乘积→分解彻底。

    2. 提公因式法：ma+mb+mc = m(a+b+c)。易错点：注意项的符号与幂指数，公因式要提"干净"，某项恰为公因式时提出后括号内该项为 +1 不漏写。

    3. 运用公式法：a²−b²=(a+b)(a−b)；a²±2ab+b²=(a±b)²。易错：要分解到底，如 x⁴−y⁴=(x²+y²)(x²−y²) 还应继续分解为 (x²+y²)(x+y)(x−y)。

    4. 怎样选公式：平方差公式适用于二项式、每项均为平方、两项异号；完全平方公式适用于三项式、两项同号各为平方、另一项为底数乘积的 2 倍。

    5. 分组分解法：am+an+bm+bn = a(m+n)+b(m+n) = (a+b)(m+n)。关键是分组后能否提公因式或继续用公式，分组时注意符号变化。

    6. 十字相乘法：对二次三项式，竖分二次项与常数项系数，交叉相乘再相加等于一次项系数，横写因式。顺口溜：竖分常数交叉验，横写因式不能乱。例：x²+6x−7=(x+7)(x−1)。

    经验之秘：分解因式一般先提公因式，再用公式法或其他方法；必须把每个因式都分解到不能再分解为止。

    第一章 分式 · 概念与性质

    分式的定义：A、B 为整式且 B 中含字母，则 A/B 叫做分式（A 为分子，B 为分母）。

    与分式有关的条件：① 有意义 ⇔ B≠0；② 无意义 ⇔ B=0；③ 值为 0 ⇔ A=0 且 B≠0；④ 值为正 ⇔ A、B 同号；⑤ 值为负 ⇔ A、B 异号；⑥ 值为 1 ⇔ A=B；⑦ 值为 −1 ⇔ A+B=0。

    基本性质：分子分母同乘（或除以）一个不等于 0 的整式，分式的值不变，A/B = AC/BC（C≠0）。注意 C≠0 的限制及隐含 B≠0。

    符号法则：分子、分母与分式本身的符号，改变其中任意两个，分式的值不变，即 A/B = (−A)/(−B) = −A/B = A/(−B)。

    运算 约分 · 通分

    约分：把分子分母的公因式约去。步骤：先因式分解，再约去公因式；单项式直接约分（约去系数最大公约数、相同因式最低次幂），多项式先分解再约。

    最简分式：分子分母没有公因式的分式。

    通分：把异分母分式化成与原来相等的同分母分式。最简公分母：取各分母所有因式的最高次幂的积。确定步骤：Ⅰ 系数取最小公倍数；Ⅱ 单独出现的字母连同指数作因式；Ⅲ 相同字母取指数最大；Ⅳ 凡出现的字母都要取（分母为多项式先分解）。

    运算 四则运算与乘方

    乘法：a/b · c/d = ac/bd；除法：a/b ÷ c/d = a/b · d/c = ad/bc。

    乘方：(a/b)ⁿ = aⁿ/bⁿ。

    加减：同分母 a/c ± b/c = (a±b)/c；异分母 a/b ± c/d = (ad±bc)/bd；整式与分式加减时把整式看作分母为 1 的分式（带负号要加括号）。

    混合运算顺序：先乘方，再乘除，后加减；同级从左，有括号先算括号内。

    注意：每步变形要明确目的与依据，格式规范，不随便跳步，便于查对错误。
    方程 分式方程

    基本思想：把分式方程转化为整式方程。

    一般步骤：① 两边乘最简公分母去分母；② 解整式方程；③ 验根：把根代入最简公分母，为 0 的是增根须舍去（含字母系数的一般不验根）。

    例1解方程 x/(x−1) − 2/(x+1) = 1。
    解：两边乘 (x+1)(x−1) 得 x(x+1)−2(x−1)=(x+1)(x−1) ；整理 x²+x−2x+2 = x²−1 ⇒ −x = −3 ⇒ x=3/2 ；经检验 x=3/2 是原方程的根。✓
    中考分式方程 2x/(x+1) − (m+1)/(x²−x) = (x+1)/(x−1) 产生增根，求 m。 A.−1或2　B.−1或2　C.1或2　D.1或−2
    解：增根为使分母为 0 的值，即 x=0 或 x=−1 ；代入化简后的整式方程 2x²−(m+1)=(x+1)² ，分别得 m=1 或 m=−2 ，选 D。
    题型m 为何值时，方程 2/(x²−4) + mx/(x(x+2)) = 3/(x+2) 会产生增根？
    解：乘 x²−4 得 2x+4+mx=3x−6 ⇒ (m−1)x=−10 ；增根 x=±2 ；代入 x=2 ⇒ m=−4 ，x=−2 ⇒ m=6 ；故 m=−4 或 6 时产生增根。✓
    说明：分式方程的增根，一定是使最简公分母为零的根。

    第三章 勾股定理 · 知识概念

    1. 勾股定理：直角三角形两直角边 a、b 的平方和，等于斜边 c 的平方，即 a²+b²=c²。

    要点诠释：勾股定理反映直角三角形三边关系，主要应用：
    ① 已知两边求第三边（∠C=90° 时 c=√(a²+b²)，b=√(c²−a²)，a=√(c²−b²)）；
    ② 已知一边与另两边关系，求另两边；
    ③ 证明线段平方关系。

    2. 勾股定理的逆定理：若三角形三边长 a、b、c 满足 a²+b²=c²，则这个三角形是直角三角形。

    要点诠释：
    ① 先确定最大边，设最长边为 c；
    ② 验证 c² 与 a²+b² 是否相等，若 c²=a²+b² 则 △ABC 是以 ∠C 为直角的直角三角形。

    ★ 拓展：若 c²>a²+b² 则 △ABC 是以 ∠C 为钝角的钝角三角形；若 c²<a²+b² 则为锐角三角形。

    3. 勾股定理与逆定理的区别与联系：
    区别：勾股定理是性质定理，逆定理是判定定理；
    联系：二者题设与结论正好相反，都与直角三角形有关。

    4. 互逆命题：若一命题的题设和结论分别是另一命题的结论和题设，这两个命题叫互逆命题；其中一个叫原命题，另一个叫它的逆命题。

    规律方法 指导

    1. 勾股定理的证明采用图形面积与代数恒等式相互转化的思想。

    2. 勾股定理反映直角三角形三边数量关系，可求解边边关系。

    3. 应用时一定要弄清谁是斜边、谁是直角边（易错点）。

    4. 逆定理给出判定直角三角形的方法：若 a²+b²=c² 则 △ABC 是直角三角形。

    5. 用逆定理判定时主要进行代数运算，加深对"数形结合"的理解。

    ★ 注意：a²+b²=c² 只是表现形式之一。若 a²+c²=b²，则以 a,b,c 为边的三角形是直角三角形，但 b 是斜边。

    证明 勾股定理的拼图法

    5. 勾股定理的证明（常见"拼图"方法）：图形割补拼接后无重叠无空隙则面积不变 → 用同一图形面积的两种表示列式推导。

    ● 方法一：4×S△ + S正EFGH = S正ABCD，即 4×12ab + (b−a)² = c²，化简可证。

    ● 方法二：四个直角三角形与小正方形面积之和 = 大正方形面积：4×12ab + c² = (a+b)² = a²+2ab+b²，故 a²+b²=c²。

    6. 勾股数：能构成直角三角形的三边长的三个正整数，即 a²+b²=c² 中 a,b,c 为正整数时称一组勾股数。

    ★ 常见勾股数：3,4,5；6,8,10；5,12,13；7,24,25。

    第四章 四边形 · 知识概要

    1. 平行四边形定义：有两组对边分别平行的四边形。记 AB∥CD，AD∥BC；AB=CD，AD=BC；∠A=∠C，∠B=∠D。

    2. 平行四边形性质：对边相等；对角相等；对角线互相平分。

    3. 平行四边形判定（四条）：
    ① 两组对边分别相等的四边形是平行四边形；
    ② 对角线互相平分的四边形是平行四边形；
    ③ 两组对角分别相等的四边形是平行四边形；
    ④ 一组对边平行且相等的四边形是平行四边形。

    4. 三角形中位线：平行于第三边，且等于第三边的一半。

    5. 直角三角形斜边上的中线等于斜边的一半。

    6. 矩形定义：有一个角是直角的平行四边形。

    7. 矩形性质：四个角都是直角；对角线平分且相等，AC=BD。

    8. 矩形判定：① 有一个角是直角的平行四边形；② 对角线相等的平行四边形。

    9. 菱形定义：邻边相等的平行四边形。

    10. 菱形性质：四条边都相等；两条对角线互相垂直，且每一条对角线平分一组对角。

    11. 菱形判定（三条）：① 一组邻边相等的平行四边形；② 对角线互相垂直的平行四边形；③ 四条边相等的四边形。

    12. 菱形面积：S菱形 = a·b2（a、b 为两条对角线）。

    13. 正方形定义：一个角是直角的菱形，或邻边相等的矩形。

    14. 正方形性质：四条边都相等，四个角都是直角；既是矩形又是菱形。

    15. 正方形判定：① 邻边相等的矩形；② 有一个角是直角的菱形。

    16. 梯形定义：一组对边平行、另一组对边不平行的四边形。

    17. 直角梯形：有一个角是直角的梯形。

    18. 等腰梯形定义：两腰相等的梯形。

    19. 等腰梯形性质：同一底上的两个角相等；两条对角线相等。

    20. 等腰梯形判定：同一底上两个角相等的梯形是等腰梯形。

    2. 四个特点：① 只含一个未知数；② 未知数最高次数是 2；③ 是整式方程；④ 可化为一般形式 ax²+bx+c=0（a≠0）。

    3. 一般形式：ax²+bx+c=0（a≠0）。ax² 是二次项（a 是二次项系数），bx 是一次项（b 是一次项系数），c 是常数项。

    5. 根的判别式：△ = b²−4ac。△＞0 两不等实根；△=0 两相等实根；△＜0 无实根。

    直接开平方法：适用于 (x+a)²=b。当 b≥0，x+a=±√b；b＜0 无实根。

    配方法：依据完全平方公式，化为 (x+p)²=q。步骤：化为一般式 → 二次项化 1、常数右移 → 两边加一次项系数一半的平方 → 开方。

    公式法：x=−b±√b²−4ac2a（b²−4ac≥0）。用公式法须先化为一般式并算 △。

    因式分解法：最常用。先化一般式且二次项系数为正，再分解求解。

    方法选择：先观察能否开平方、分解因式；找不到简便方法时化为一般式用公式法。

    基本知识点 相似形 · 比例线段

    1. 相似形：图形的放缩运动——形状相同、大小不一定相同的图形叫相似图形（相似形）。

    2. 相似多边形：对应角相等、对应边成比例的多边形叫相似多边形；相似比（对应边的比）用 k 表示。

    3. 比例线段：四条线段 a、b、c、d 中，若 a:b=c:d（即 ad=bc），则称 a、b、c、d 成比例。其中 a、d 叫比例外项，b、c 叫比例内项；d 叫 a、b、c 的第四比例项。

    当 b=c 时 b²=ac，b 叫 a、c 的比例中项。

    比例性质 基本 · 反 · 更 · 合 · 等

    基本性质：a:b=c:d ⇔ ad=bc。

    反比性质：a:b=c:d ⇒ b:a=d:c。

    更比性质：a:b=c:d ⇒ a:c=b:d（内项互换 / 外项互换）。

    合比性质：a:b=c:d ⇒ (a±b):b=(c±d):d。

    等比性质：a:b=c:d=…=m:n（b+d+…+n≠0）⇒ (a+c+…+m):(b+d+…+n)=a:b。常用设 k 法：令各比 = k 计算。

    黄金分割 黄金比 ≈ 0.618

    点 C 把线段 AB 分成 AC、BC，若 AC²=AB·BC（即 AC:AB=BC:AC），则称 C 为 AB 的黄金分割点。

    AC = √5−12 · AB ≈ 0.618 AB；黄金比 √5−12 ≈ 0.618。

    黄金矩形：宽与长之比为黄金比；黄金分割在几何作图与艺术中应用广泛。

    平行线分线段 A 字型 · 8 字型

    平行线分线段成比例定理：三条平行线截两条直线，所截得的对应线段成比例。

    推论：平行于三角形一边的直线截其他两边（或两边延长线），所得对应线段成比例。

    逆定理：若一条直线截三角形的两边所得线段成比例，则这条直线平行于第三边。

    三角形一边平行线 性质 · 判定 · 重心

    性质定理：平行于三角形一边的直线截其他两边，截得的三角形与原三角形相似。

    推论：平行于三角形一边的直线和其他两边相交，所构成的三角形三边与原三角形三边对应成比例。

    判定定理：如果一条直线截三角形的两边（或两边延长线）所得对应线段成比例，那么这条直线平行于第三边。

    重心：三角形三条中线的交点叫重心。重心到顶点的距离 = 到对边中点距离的 2 倍（顶点距重心 : 重心距中点 = 2 : 1）。

    相似三角形 定义 · 性质

    定义：对应角相等、对应边成比例的三角形叫相似三角形（相似比 k）。

    性质：①对应角相等，对应边成比例；②对应高、对应角平分线、对应中线、周长的比都等于相似比；③面积比 = 相似比的平方（S₁:S₂=k²）。

    判定定理 两角 · 两边夹角 · 三边

    判定 1：两角对应相等的两个三角形相似。

    判定 2：两边对应成比例且夹角相等的两个三角形相似。

    判定 3：三边对应成比例的两个三角形相似。

    直角三角形相似：①一个锐角相等；②两条直角边对应成比例；③斜边与一条直角边对应成比例。

    直角三角形被斜边上的高分成的两个直角三角形与原三角形都相似。

    补充 射影定理 · 等腰/直角推论

    射影定理（Rt△斜边上的高）：CD²=AD·BD，AC²=AD·AB，BC²=BD·BA（在直角三角形计算和证明中应用广泛）。

    等腰三角形相似推论：①顶角相等；②底角相等；③腰和底对应成比例——满足其一即相似。

    直角三角形相似推论：①有一锐角相等；②斜边上的高把原三角形分成两个都与原三角形相似的三角形；③两边及其中一边上的中线对应成比例则相似。

    应用 · 位似 位似中心 · 位似比

    定义：如果两个多边形不仅相似，而且对应顶点的连线相交于一点，则这两个图形叫位似图形，该点叫位似中心，此时的相似比又称位似比。

    需注意：①位似是具有位置关系的相似；②位似中心唯一；③两图形可在位似中心两侧或同侧；④位似比即相似比。

    性质：①位似图形具有相似图形的一切性质；②任意一对对应点到位似中心的距离比 = 位似比；③每对对应点与位似中心共线，不经过位似中心的对应线段平行。
