# 个人图书馆内容区

这个目录里的每一本书，都是一个**自包含的 HTML 单文件**。把它放进前台书架的目录里就行。

---

## 怎么加一本书

### 最简做法（三步）

1. 新建一个目录，目录名就是书 id（小写字母 + 连字符）：

   ```
   public/books/my-book/
   ```

2. 把做好的 HTML 放进这个目录，**文件名必须是 `index.html`**：

   ```
   public/books/my-book/index.html
   ```

3. 跑一下生成命令（或直接 `npm run build`）：

   ```bash
   npm run gen:books
   ```

   前台 `/books` 刷新就能看到这本书了。

### 完整做法（推荐，带 meta.json）

再放一个 `meta.json`，书名/简介/分类/标签/封面就能写得漂亮些：

```json
{
  "title": "道德经",
  "description": "道可道，非常道。老子五千言。",
  "cover": "cover.png",
  "category": "国学经典",
  "tags": ["老子", "道家"],
  "order": 10
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 否 | 书名。不写则自动抓 HTML 的 `<title>`，再不行就用目录名 |
| `description` | 否 | 简介。不写则自动抓 HTML 的 `<meta name="description">` |
| `cover` | 否 | 封面文件名（放在同目录下）。不写则卡片用彩色占位块 |
| `category` | 否 | 分类名。不写则归入「未分类」 |
| `tags` | 否 | 标签数组，参与搜索 |
| `order` | 否 | 排序权重，数字越小越靠前。不写则排在有 order 的书之后 |

> **`meta.json` 全部可选。** 缺了它书照样能显示，只是书名和简介要靠自动抓取。

---

## 硬性要求

**HTML 必须是自包含单文件**，即 CSS / JS / 图片全部内联在这一个文件里，不依赖 CDN、不引用同目录外的文件。

原因：这些书要能部署到 nginx 或 `serve` 上直接吐出，任何外部依赖都可能因为网络原因打不开。你的 HTML 单文件动辄几十万字符，正好符合这个要求。

---

## 目录规则

| 规则 | 说明 |
|---|---|
| 一本书 = 一个目录 | 目录名即 `id`，出现在 URL `/books/<id>/index.html` |
| `_` 开头的目录会被跳过 | `_template/` 是模板目录，不会出现在书架上 |
| 缺 `index.html` 的目录会被跳过 | 生成时会控制台告警，不会静默吞掉 |

---

## manifest.json 是自动生成的

`public/books/manifest.json` 由 `scripts/gen-books-manifest.cjs` 生成，**不要手改**（改了会在下次生成时被覆盖）。

需要手写元信息就改各本书目录下的 `meta.json`，那个是安全的手写入口。

**这个文件是入 git 的**：这样本地 dev 不跑生成脚本也能看到全部书，部署时再刷新一次即可。

---

## 关于「上传」功能

前台书架上的「上传」按钮可以把 HTML 存在**你自己浏览器的 IndexedDB**里（不上传到服务器、别的设备也看不到）。

它和本目录是两套数据：这里的书跟着 git 和部署走，上传的书只跟着这台设备走。想让一本书所有人都能看到，还是得放回这个目录。
