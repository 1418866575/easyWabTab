好的，我把统一社会信用代码的完整格式和规则详细给你列一下。

一个标准的统一社会信用代码是**18位**，由**数字和大写字母**组成（**不含** I、O、Z、S、V 五个字母）。它由以下五部分构成：

---

**第1位：登记管理部门代码（1位字符）**
表示在哪个部门登记注册的。

- `1` = 机构编制（如事业单位）
- `2` = 外交
- `3` = 司法行政
- `4` = 公安
- `5` = 民政（如社会团体、民办非企业）
- `9` = 工商（如公司、个体户）——最常见
- `Y` = 其他

**第2位：机构类别代码（1位字符）**
表示具体的机构类型，由对应的登记管理部门分配。

- 比如在工商登记（9）下：
  - `1` = 企业法人
  - `2` = 合伙企业
  - `3` = 个人独资企业
  - `4` = 农民专业合作社
  - `5` = 个体工商户
  - `9` = 其他

**第3-8位：登记管理机关行政区划代码（6位数字）**
表示注册地的行政区划，精确到县（区）级。

- 例如：`110105` = 北京市朝阳区；`440101` = 广东省广州市市辖区

**第9-17位：主体标识码（9位字符）**
这个就是原来的“组织机构代码”，是给每个机构的唯一编码。由数字或大写字母组成。

**第18位：校验码（1位数字或大写字母）**
根据前面17位，通过国家标准（GB/T 36103-2018）规定的加权公式计算出来的，用于检验代码是否正确。计算结果可能是0-9，也可能是`X`（代表10）。

### 一个简单的自查清单

如果你手上有代码，可以对照下面检查：

- [ ] 是不是**刚好18位**？（多一位少一位都不行）
- [ ] 里面有没有 **I、O、Z、S、V** 这五个字母？（有的话就错了）
- [ ] 第3到第8位是不是**纯数字**（行政区划代码）？
- [ ] 第18位是不是数字或 `X`？
