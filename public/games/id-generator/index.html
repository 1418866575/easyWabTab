📋 身份证号组成说明

地址码 110101 前6位，表示编码对象常住户口所在县(市、区)的行政区划代码
出生日期 19900315 第7-14位，表示出生年月日（YYYYMMDD格式）
顺序码 001 第15-17位，同一地址码所标识的区域范围内同年同月同日出生的人编定的顺序号；第17位奇数=男，偶数=女
校验码 X 第18位，ISO 7064:1983, Mod 11-2 校验码（GB 11643-1999）；0-9或X（X代表10）查看计算规则
示例：11010119900315001X = 11010119900315001X

🔢 校验码计算规则（GB 11643-1999）

计算步骤：

  1. 取身份证前17位数字 a1~a17（第1位为最高位）
  2. 每位乘以对应的加权因子 Wi，求和：S = Σ(ai × Wi)
  3. 计算余数：R = S mod 11（结果 0~10）
  4. 根据余数 R 查校验码映射表得出第18位

加权因子表 Wi（对应前17位）：

位数1234567891011121314151617
Wi7910584216379105842

校验码映射表（余数 R → 校验码）：

余数 R012345678910
校验码10X98765432

余数 2 → 校验码为 X（代表 10），其余直接取对应数字

示例验证：

以 11010119900315001X 为例：
S = 1×7 + 1×9 + 0×10 + 1×5 + 0×8 + 1×4 + 1×2 + 9×1 + 9×6 + 0×3 + 0×7 + 3×9 + 1×10 + 5×5 + 0×8 + 0×4 + 1×2
= 7 + 9 + 0 + 5 + 0 + 4 + 2 + 9 + 54 + 0 + 0 + 27 + 10 + 25 + 0 + 0 + 2 = 154
R = 154 mod 11 = 0 → 查表得校验码 = 1
完整身份证号：110101199003150011
