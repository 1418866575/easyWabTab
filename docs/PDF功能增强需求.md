# PDF 功能增强需求

> 版本：v1 · 日期：2026-10-03
> 目标：参考主流免费 PDF 工具站点（iLovePDF），对照本仓库「工具箱」已有 PDF 能力，补齐可纯前端落地的功能，并规划需服务端/重算力才能实现的后续项。

## 1. 背景与目标

本仓库 `easy-web-tab` 工具箱（`src/toolbox/`）已内置一批 PDF 相关工具，但覆盖面与主流在线 PDF 站仍有差距。本需求旨在：

- **目标 1（对标）**：梳理 iLovePDF 的 PDF 功能清单，明确能力边界。
- **目标 2（补位）**：在不违反「零上传 / 纯前端」硬约束的前提下，把能在浏览器本地完成的 PDF 功能落地为工具箱新工具。
- **目标 3（规划）**：明确无法纯前端高保真实现的项（如 Office 互转、PDF/A、数字签名、OCR 等），列入后续规划，待引入合适本地库或接受降质方案时再落地。

**硬约束（不可突破）**：全部工具纯前端、本地处理，绝不上传文件到任何第三方服务器。因此凡依赖服务端渲染、重算力或第三方 API 的能力，一律不即时实现，仅列入规划。

## 5. 各新增工具详细范围

### 5.1 `image-to-pdf`（图片转 PDF）— P0
- **目标**：把多张本地图片拼成一份 PDF，便于归档/打印。
- **输入**：本地图片文件（多选），支持 PNG/JPG；其他格式（WebP/BMP/GIF 首帧）经 canvas 绘制为位图后再嵌入。
- **功能范围**：
  - 页面尺寸：① 按图片原始像素（1px=1/72in）；② 适配 A4（等比缩放后居中，可选边距）。
  - 顺序：按选择顺序；支持列表内上移/下移/删除。
  - 输出：`image-to-pdf-<timestamp>.pdf`，一键下载。
- **不做什么**：不做图片编辑/滤镜（已有 image-* 系列工具）、不压缩重采样（体积由图本身决定）。
- **优先级理由**：需求高频、实现稳健、零依赖风险（pdf-lib 原生支持 PNG/JPG 嵌入）。

### 5.2 `pdf-page-numbers`（添加页码）— P0
- **目标**：为 PDF 每页添加可定位的页码。
- **功能范围**：
  - 位置：下中、下右、下左、上中、上右、上左（六选一）。
  - 格式：`n`（纯数字）、`第 n 页`、`n / N`（含总页数）。
  - 起始页码：默认 1，可自定义（如封面不计入）。
  - 字号、距边距距离可调；字体用标准 Helvetica（pdf-lib 内置，无需外部字体）。
  - 输出：`<原名>-numbered.pdf`。
- **不做什么**：不替换已有页脚文字、不做奇偶页差异（后续可扩展）。
- **优先级理由**：高频、纯 pdf-lib 绘制即可，风险低。

### 5.3 `pdf-unlock`（解锁 PDF）— P1
- **目标**：移除 PDF 的打开密码保护（用户提供已知密码）。
- **功能范围**：
  - 输入加密 PDF + 用户填写的打开密码。
  - `PDFDocument.load(data, { password })` 成功后再 `save()`（默认不加密）→ 得到无密码 PDF。
  - 错误提示：密码错误 / 非加密文件 / 解析失败。
- **明确边界**：**不做密码爆破**；无法处理未知密码的加密 PDF（纯前端算力不现实）。
- **优先级理由**：pdf-lib 原生支持带密码加载，实现简单；但属安全相关，标注 P1 并清晰告知边界。

### 5.4 `pdf-extract` 增强（PDF 转图片完善）— P1
- **目标**：让已有的「页面转图片」更实用。
- **范围**：图片模式增加 **PNG / JPG** 格式切换；增加 **下载全部为 ZIP**（jszip）按钮；其余逻辑不变。
- **理由**：避免新增一个与 `pdf-extract` 重复的 `pdf-to-image` 工具，复用现有入口，减少工具箱冗余。

## 6. 实现约束与一致性

- **零上传**：所有工具只用 `File`/`ArrayBuffer`/`<canvas>`/Blob，绝不发网络请求。
- **复用**：渲染用 `pdfjs-dist`（worker 经 `?url` 引入，参照 `pdf-extract`）；写盘用 `pdf-lib`；打包用 `jszip`；下载统一走 `core/download.ts` 的 `downloadBlob`。
- **UI 一致**：沿用 `tool-ui.css` 的 `tu-t1/tu-t2`、`tu-field`、`tu-btn`、`.tu-alert`、`.tu-preview` 等；弹框尺寸 S/M/L/XL 按内容选（图片类用 L，其余 M）。
- **注册**：`registry.ts` 经 `import.meta.glob` 自动扫描 `tools/*/index.ts`，新增目录即生效，无需改注册表。
- **类型检查**：项目 `build` 脚本不含 `vue-tsc`；但提交前仍按惯例跑 `vite build` 确认打包无错；既有的 master 预存类型错误不在本次范围。
