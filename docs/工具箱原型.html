🕘 最近使用

配置驱动 · 站内自建：新增工具只需在 TOOLBOX_TOOLS 数组追加一条元数据 （id / name / icon / description / category / tags / status / kind）， 页面渲染、搜索、筛选、收藏与最近使用全部自动生效，无需改动任何页面逻辑。 其中 kind: 'internal' 表示本站自己实现的工具（在 TOOLBOX_HANDLERS 补一个同名实现函数即可，面板内直接可用）； kind: 'module' 表示复用站内已有模块（走站内路由）。 所有工具均在站内打开，不会跳转任何第三方网站。
