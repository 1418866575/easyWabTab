# 博客后台 · 发布到微信公众号草稿箱 — 功能介绍与使用指南

## 一、功能简介

「发布到微信公众号草稿箱」是博客后台的一项发布能力：你写好博客文章后，无需手动复制粘贴到公众号后台，只需点一下，系统就会把文章（含正文插图、封面）整理成一篇公众号**草稿**，直接投递到你的公众号「草稿箱」里，待你在公众号后台确认无误后再群发。

它能帮你做三件事：

- **正文插图自动上传**：文章里用到的图片，发布时由后端自动上传到微信图床，文章里的图片链接会被替换成微信自家地址，避免公众号里图片裂图。
- **封面上传**：发布时指定的封面图会上传到微信素材库，拿到 `media_id` 作为草稿封面。
- **一键创建草稿**：标题、作者、摘要、正文、封面拼装好，调用微信草稿接口生成草稿，而不是立刻群发——你始终保留最后把关的权利。

> 重要：本功能只创建**草稿**，不会自动群发。草稿生成后，请到公众号后台「内容与互动 → 草稿箱」中检查、预览，再手动群发。

---

## 二、使用前准备（前置条件）

在动手配置前，请确认以下三件事已就绪：

### 1. 拥有一个已认证的微信公众号，并拿到 AppID / AppSecret
- 登录 [微信公众平台](https://mp.weixin.qq.com)，进入「设置与开发 → 基本配置」。
- 记录 **开发者 ID（AppID）** 和 **开发者密码（AppSecret）**。AppSecret 只在首次生成时完整显示一次，请妥善保存。
- 草稿箱接口（`draft/add`）需要公众号已通过微信认证，未认证的个人订阅号可能不具备该接口权限。

### 2. 把服务器公网 IP 加入公众号 IP 白名单
- 仍在「基本配置」页面，找到「IP 白名单」。
- 把**部署本系统的服务器出口公网 IP** 添加进去。
- 这一步极易被忽略：如果没加白名单，调用接口会报 `40164 / 61004`（IP 未授权），凭证明明正确却校验失败。

### 3. 后端代理服务已部署并运行
- 本功能依赖一个常驻的后端代理服务，它**不保管任何凭证**（AppSecret 由前端随每次请求提交，代理仅按 AppID 维度缓存 `access_token` 并调用微信接口、上传图片），经 nginx 反代 `/api/wechat` 暴露给前端。
- 部署时请确保该服务已启动且在监听，且 nginx 已正确配置 `/api/wechat` 转发。若该服务未启动或未配置，发布请求无法送达微信，前端会明确提示失败。

## 三、配置步骤（填写公众号凭证）

凭证只需配置一次，之后所有文章发布都会复用；凭证保存在**本机浏览器**，并随博客云同步（blog.json 信封）在你的多台设备间自动同步。

1. 打开博客后台，进入 **博客设置**（博客管理区域内的设置入口）。
2. 在设置页左侧导航中找到 **微信公众号**（位于「标签管理」下方，与博客设置 / 分类管理 / 标签管理同页）。
3. 填入两项：
   - **AppID**：公众号的开发者 ID（16–32 位字母数字）。
   - **AppSecret**：开发者密码（32–64 位字母数字；首次配置必填，之后留空表示沿用已保存值，无需每次重填）。
4. 点击 **保存凭证**。系统会把凭证写入本机并在后台尝试向微信请求一次 `access_token` 做真实性校验：
   - 校验通过 → 提示「凭证有效（已通过微信校验），并保存到本地」。
   - 校验未通过（代理不可达或微信报错）→ 提示具体错误；**凭证仍会保存到本机**，待部署好代理 / 修正白名单后可重新校验。
5. 配置成功后，设置页只展示**脱敏后的 AppID**（如 `wx12****3456`）和「是否已配置」的状态，原始 AppSecret 不会出现在界面上。

> 安全说明：AppSecret 保存在你自己的浏览器本地，并随你配置的云同步（WebDAV / 飞书）在设备间同步；服务端代理**绝不落盘**任何凭证，只按 AppID 维度缓存 `access_token`。多用户共用同一部署时，各人凭证相互独立、互不串号。若担心云端明文，可在不开启云同步的情况下仅本机使用。

## 四、使用步骤（发布一篇文章）

1. 在博客编辑器中**撰写文章**（支持 Markdown，可用分屏实时预览）。
2. **插入正文图片**：编辑时正常插入图片即可；发布环节系统会自动把这些图片上传到微信图床并替换链接，无需你手动处理。
3. **设置封面**：在发布前指定一张封面图（封面同样会由后端上传到微信素材库）。
4. 点击编辑器工具栏 / 底部的 **「发布到公众号」** 按钮。
5. 系统依次完成：上传正文插图 → 上传封面 → 调用草稿接口创建草稿。
6. 发布成功后，登录公众号后台，进入 **「内容与互动 → 草稿箱」**，即可看到这篇草稿：
   - 检查排版、图片、封面是否正确；
   - 确认无误后点「发表 / 群发」。

## 五、注意事项与限制

- **标题与摘要长度**：微信对标题限制 64 字、摘要 120 字。超出部分系统会**自动截断**，不会整篇发布失败，但请留意长标题被截短。
- **图片格式**：微信图床仅接受 **JPG / PNG**。若文章插图是 WebP / AVIF 等格式，需先在前端转为 JPG/PNG 再插入，否则上传会报错。
- **图片体积**：单张图最大约 12MB，过大或过多的图会增加上传耗时。
- **只进草稿箱**：本功能绝不自动群发，所有文章先落草稿，由你人工确认后发出。
- **IP 白名单**：务必保证白名单里的 IP 是服务器**实际出口 IP**（云服务器注意 NAT / 弹性 IP 场景），IP 变动后需同步更新白名单，否则校验与发布都会失败。
- **凭证安全**：AppSecret 等同于公众号的「写权限钥匙」，保存在你本机浏览器（可随云同步）；如怀疑泄露，请到公众平台重置 AppSecret 并在本系统重新保存。服务端代理不保存任何凭证。

## 六、常见问题

**Q：保存凭证时提示「微信校验未通过」，但 AppID / AppSecret 看起来没错？**
A：九成是 IP 白名单问题。请确认「基本配置 → IP 白名单」里填的是本系统服务器的公网出口 IP，而不是内网 IP 或你本地电脑的 IP。改完白名单通常几分钟内生效，可重新点保存再校验一次。

**Q：点「发布到公众号」后失败，提示图片相关错误？**
A：多半是图片格式不被微信接受（如 WebP / AVIF），或单图超过体积上限。请改为 JPG / PNG 后再发布。

**Q：发布后公众号草稿箱里找不到文章？**
A：请确认后端代理服务已正常运行、nginx 的 `/api/wechat` 转发已生效。若服务未启动，前端会明确提示「代理服务未启动」，此时发布请求无法送达微信。

**Q：草稿里的图片裂了 / 显示异常？**
A：正常发布流程会把图片替换为微信图床地址。若仍裂图，通常是发布时图片上传环节失败（格式 / 体积 / 网络），可重新发布一次；个别情况下微信图床偶发延迟，稍等刷新即可。

**Q：能不能直接群发，跳过草稿箱？**
A：出于安全与内容把关考虑，本功能只创建草稿，群发动作留在公众号后台由你手动完成。这样可以在正式发出前检查排版与封面，避免误发。
