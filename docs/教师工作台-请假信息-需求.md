# 教师工作台 · 请假信息 —— 需求说明（v1）

## 1. 背景与目标

教师工作台已有课程表、点名、学生信息、座位表、成绩、试卷、值日、家长联系、奖励记录等模块，
但**学生出勤中的「请假」环节缺失**：班主任目前只能在纸质假条或微信里处理请假，无法与班级学生数据关联，
也无法统计「谁经常请假、请了几天、什么原因」。

本需求新增 **请假信息** 模块，让班主任在一个页面完成：**登记 → 审批 → 销假 → 统计 → 导出**。

## 2. 归属与权限（关键约束）

| 约束 | 说明 |
|---|---|
| **归属班主任** | 请假由班主任登记、审批、销假；模块归入 `TEACHER_HEAD_ONLY_PAGES`，与座位表 / 值日生表 / 联系家长 / 隐私信息同级 |
| **科任老师不可见** | 身份选「非班主任」时：左侧导航移除该菜单项；即使直接跳转也被 `guardPage()` 拦截回落到可见页 |
| **数据归属** | 挂在 `ClassBucket`（`groups[学期][班级]`）下，与座位表、值日、奖励记录同层，**随学期×班级隔离**；换学期/换班数据互不可见 |
| **审批人** | 默认取当前教师姓名（`data.teacher.name`），可改 |

## 3. 数据模型

```ts
export type LeaveType = '事假' | '病假' | '公假' | '丧假' | '其他'
export type LeaveStatus = 'pending' | 'approved' | 'rejected' | 'closed'  // 待审批 / 已批准 / 未批准 / 已销假

export interface LeaveRecord {
  id: string
  studentId: string      // 关联学生（主键为学号复合 id，非姓名）
  type: LeaveType
  startDate: string      // YYYY-MM-DD
  endDate: string        // YYYY-MM-DD
  days: number           // 请假天数（= 结束日 - 开始日 + 1，可手动覆盖）
  reason: string         // 请假事由
  applicant: string      // 申请人（如「张三妈妈」）
  approver: string       // 审批人（默认班主任姓名）
  status: LeaveStatus
  remark: string         // 备注（销假情况、补充说明）
  createdAt: string      // 登记时间 YYYY-MM-DD
}

// ClassBucket 新增字段
leaves: LeaveRecord[]
```

设计取舍：请假是**班级维度的流水**，不是「某学生的私有档案」，因此用数组 `leaves[]` 而非 `Record<studentId, …>`
（与 `exams[] / papers[]` 一致），便于按时间、状态、类型整体筛选与统计。

## 4. 功能需求

### 4.1 登记（增 / 改 / 删）
- 新增：选学生 → 填类型、起止日期、事由、申请人 → 保存；天数自动计算，可手动改
- 编辑：打开已有记录修改全部字段
- 删除：二次确认后删除
- **校验**：必须选学生；开始日期不能晚于结束日期；天数 > 0；事由必填

### 4.2 审批与销假
- 待审批（pending）→ 「批准」（approved）/「不批准」（rejected）
- 已批准 → 学生返校后「销假」（closed），可填销假备注
- 状态以彩色标签呈现：待审批（橙）/ 已批准（蓝）/ 未批准（红）/ 已销假（绿）

### 4.3 查询与筛选
- 关键词搜索（学生姓名 / 事由 / 申请人）
- 状态筛选：全部 / 待审批 / 已批准 / 未批准 / 已销假
- 类型筛选：全部 / 事假 / 病假 / 公假 / 丧假 / 其他
- 默认按开始日期倒序

### 4.4 统计卡片
- **正在请假**：已批准且结束日期 ≥ 今天的人数
- **本月人次 / 本月天数**：本月内登记的请假人次与累计天数
- **待审批**：待处理条数
- **按类型分布**：本月各类型人次（小条形图）

### 4.5 导出
- 「导出 / 打印」走 `window.print()`（与奖励记录一致，打印样式 `.tw-no-print` 已具备）
- 「导出 CSV」生成带 BOM 的 CSV 下载，供 Excel 打开

### 4.6 数据联动与边界
- 删除学生时**级联清理**其请假记录（`removeStudentCascade`）
- 切换学期 / 班级：数据自动切换，互不干扰
- 旧数据兼容：`normalizeBucket` 对缺失 `leaves` 兜底为 `[]`，字段非法逐项兜底，绝不抛错
- 持久化：沿用 IndexedDB `teacher_workbench` 单对象 + `markDirty()` 云同步，无需新增存储
- 空态：无学生 / 无记录时给出明确引导文案

### 4.7 移动端
- ≤768px：统计卡片两列、表格转卡片流、工具栏换行，按钮 ≥44px（沿用项目 `mobile.css` 约定）

## 5. 非目标（v1 不做）

- 与「提醒设置」的到期提醒联动
- 附件（病假条照片）上传
- 请假条 PDF 排版打印模板
- 跨学期汇总统计

## 6. 验收清单

1. 班主任身份下左侧菜单出现「请假信息」；切「非班主任」后消失且无法直达
2. 新增一条请假 → 列表出现 → 刷新页面仍在（IndexedDB 持久化）
3. 批准 → 状态变「已批准」；销假 → 变「已销假」
4. 删除学生后，其请假记录一并清除
5. 切换学期/班级后数据独立
6. 筛选、搜索、统计数字与列表一致
7. 导出 CSV 能被 Excel 正常打开（中文不乱码）
