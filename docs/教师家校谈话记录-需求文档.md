# 教师工作台 · 家校谈话记录（需求文档）

> 范围：班主任（homeroom teacher）工作台。目标：把班主任日常与家长的沟通（电话 / 微信 / 面谈 / 家访等）结构化记录下来，便于回溯、统计与跟进，替代"写在笔记本/微信群聊里找不到"的现状。

---

## 1. 背景与真实场景

班主任在家校沟通上的高频动作（基于中小学实际）：

- **学业沟通**：某生成绩明显下滑 / 偏科 → 致电家长，约定辅导计划。
- **行为与纪律**：上课违纪、与同学冲突 → 约家长面谈，明确家校配合要求。
- **心理与情绪**：学生情绪低落、焦虑 → 联系家长了解家庭变故 / 亲子矛盾。
- **家访**：按学校要求定期上门家访，记录家访见闻与建议（中国特色、班主任专属）。
- **出勤与安全**：旷课 / 请假 / 防溺水·交通等安全提醒 → 通知并确认家长知悉。
- **政策与资助**：贫困资助、营养餐、分班 / 升学等政策性沟通。

痛点：沟通零散在微信聊天、纸条、脑子里；换手机 / 过段时间就找不到"上次跟 XX 家长说了啥、约了啥"。本模块让每次谈话成为一条可检索、可统计、可跟进的记录。

---

## 2. 适用范围与角色

- **归属**：班主任专属模块，建议进入 `TEACHER_HEAD_ONLY_PAGES`（科任老师不显示）。
  - 备注：现实中偶尔科任也会联系家长，但本需求按用户要求"属于班主任"，先定为班主任专属；若日后要放开，仅需把菜单项移出 head-only 集合即可。
- **数据隔离**：按班级（ClassBucket）隔离，随当前班级信封走云同步，与现有各模块一致。

---

## 3. 数据模型

单条记录 `HomeSchoolTalkRecord`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 主键（uid） |
| `studentId` | string | 关联学生（默认单学生；一次谈话主要面向一名学生） |
| `studentName` | string | 冗余姓名，便于列表/导出直接展示 |
| `studentNo` | string | 冗余学号 |
| `date` | string | 谈话日期 `YYYY-MM-DD`（必填） |
| `time` | string? | 具体时间 `HH:MM`（选填） |
| `mode` | string | 沟通方式：电话 / 微信 / QQ / 面谈 / 家访 / 其他（下拉+可自定义，复用 `el-select filterable allow-create`） |
| `counterpart` | string | 谈话对象身份：父亲 / 母亲 / 祖父母 / 监护人 / 学生本人 / 其他 |
| `counterpartName` | string? | 对方姓名（选填） |
| `category` | string | 主题分类：学业 / 行为纪律 / 心理情绪 / 家庭情况 / 出勤请假 / 安全 / 政策资助 / 其他（预设下拉） |
| `content` | string | 谈话内容摘要（必填，多行） |
| `result` | string? | 达成的共识 / 处理结论 |
| `needFollowUp` | boolean | 是否需要后续跟进 |
| `followUpNote` | string? | 跟进事项 / 下次计划（needFollowUp 为真时填写） |
| `createdAt` / `updatedAt` | number | 时间戳 |

> 设计取舍：**一次谈话默认只关联一名学生**（绝大多数场景如此）。若同一家长一次谈及多名子女，用 `content` / `followUpNote` 自由文本补充，不引入"多学生"复杂度。

`ClassBucket` 新增字段：`talks: HomeSchoolTalkRecord[]`，并在 `emptyBucket()` / `normalizeBucket()` 中兜底 `[]`、按既有范式归一化。

## 4. 核心功能（P0 · 本期实现）

1. **新增 / 编辑 / 删除**
   - 新增弹框：选学生（下拉，复用学生列表）→ 日期（默认今天）→ 方式 / 对象 / 分类（下拉）→ 内容（必填）→ 结论 / 跟进。
   - 编辑：复用同一弹框，回显。
   - 删除：二次确认后移除（沿用既有 `showConfirm` 范式）。
2. **列表展示（对齐既有"列表 + 卡片"双视图）**
   - 复用 `useViewMode()` + `ViewModeToggle` + `src/styles/records.css`。
   - 表格列：日期 · 学生 · 方式 · 对象 · 分类 · 内容摘要（省略号截断）· 是否需跟进 · 操作。
   - 分页复用 `src/styles/pager.css` 与 `usePageSize`（PAGE_SIZES=[10,20,50]）。
3. **筛选与搜索**
   - 按学生、按方式、按分类、按"是否需跟进"筛选；按日期范围（本学期 / 近 30 天 / 全部）。
   - 关键字搜索内容 / 对方姓名（轻量，复用既有搜索框范式）。
4. **统计（卡片 / 顶部概览）**
   - 本班谈话总数；本月次数；各分类占比；**待跟进数量**（醒目提示）。
   - 统计仅本地计算，不引入图表库（与项目"内联 SVG / 不引 echarts"约定一致；必要时用简单计数卡 + 文字占比）。
5. **导出 Excel**
   - 复用 `teacherExcelCore.exportExcel` / `excelFileName`，列对应上述字段。

## 7. 待确认问题

1. **角色范围**：仅班主任可见（head-only）是否符合预期？还是科任也要用？
