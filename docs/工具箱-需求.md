# 工具箱模块 · 需求文档

> 项目：easy-web-tab（Vue 3 + Pinia + Vite）
> 分支：`20260929-toolbox`
> 文档定位：定义「工具箱」模块要做什么、给谁用、做到什么程度。设计实现见 `工具箱设计方案.md`，可运行原型见 `工具箱原型.html`。

---

## 一、模块背景

easy-web-tab 已聚合了多类工作台：**导航站（首页）、个人工作台、销售记账、学生工作台、教师工作台**。随着使用深入，用户会持续积累一批「零散但高频」的小工具与外部入口，例如：

- 常用外部站点 / 内部页面深链（如备份导入、图标管理、云同步状态）；
- 轻量小工具（后续可扩展：JSON 格式化、时间戳转换、颜色拾取等）；
- 各模块内的低频但重要的入口（不想每次翻菜单）。

这些入口当前**散落在不同模块或浏览器书签里**，缺少一个统一、可搜索、可收藏的聚合页。因此新增**「工具箱」模块**：以**配置驱动**的方式聚合工具入口，提供搜索、分类、收藏、最近使用，让「找到并打开一个工具」的成本降到最低。

设计原则：**先做薄**（聚合 + 检索 + 收藏/最近），**可生长**（工具项纯配置，新增工具不改页面逻辑）。

---

## 二、目标用户

| 用户 | 特征 | 对工具箱的诉求 |
|------|------|----------------|
| 主用户（本应用使用者） | 日常在导航站与各工作台间切换，有固定高频外链/功能入口 | 一个地方找到所有工具，越少点击越好 |
| 进阶用户 | 工具较多（几十个），有明确分类习惯 | 分类浏览 + 关键字秒搜 + 收藏置顶 |
| 后续维护者 / 开发者 | 需要不断接入新工具 | 新增工具 = 加一条配置，零改动页面 |

---

## 三、核心使用场景

1. **直达高频工具**：打开工具箱 → 常用/收藏区一眼看到 3~5 个高频工具 → 一次点击进入。
2. **按类浏览发现**：不确定名字时，用分类（如「开发工具」「数据工具」）浏览，配合标签缩小范围。
3. **关键字即时检索**：记得模糊名字（如「json」「备份」「地图」）→ 搜索框输入即得结果，名称与描述都参与匹配。
4. **回访刚用过的**：底部「最近使用」按时间倒序，快速回到几分钟前用过的工具。
5. **接入新工具（维护者）**：在工具配置里加一条 `{ id, name, icon, description, category, tags, status, url }`，页面自动出现该卡片。
6. **遇到不可用工具**：工具处于「维护中 / 即将上线」时不误导点击，给出明确状态与说明。

## 四、功能需求

### 4.1 工具列表展示
- 以**卡片式网格**展示工具，自适应列宽（空间不足自动降列）。
- 每张卡片至少包含：**图标、名称、描述、标签、状态徽标、收藏按钮**。
- 卡片整体可点击 = 打开工具（跳转）；收藏按钮点击**不触发跳转**（阻止冒泡）。
- 列表**完全由配置驱动**，页面不含任何硬编码工具。

### 4.2 分类与标签
- 每个工具归属**一个主分类**（如 开发工具 / 数据工具 / 媒体工具 / 效率工具 / 其他）。
- 每个工具可有**多个标签**（如 `json`、`格式化`、`在线`），用于搜索与辅助筛选。
- 顶部提供**分类筛选**：「全部」+ 各分类，分类项显示该分类下的工具数量。
- 分类与搜索、标签可叠加生效。

### 4.3 关键字实时搜索
- 输入**即时过滤**（`input` 事件，无需点按钮）。
- 匹配范围：**工具名称 + 描述 + 标签**（三者任一命中即算匹配）。
- 匹配方式：**大小写不敏感的模糊包含**；支持空格分词（多个词需全部命中，提升精准度）。
- 命中关键字时**高亮显示**（名称/描述中标记匹配片段），便于确认。
- 提供**一键清空**搜索词。

### 4.4 常用 / 收藏
- 每张卡片提供**收藏切换**（星标），收藏状态**本地持久化**，刷新后保留。
- 已收藏工具在页面顶部**「常用工具」分组置顶展示**，便于直达。
- 分组仅在有收藏时显示；无收藏时不占位（显示引导空态）。
- 收藏动作给出轻量反馈（toast），沿用项目 `useToast` 约定。

### 4.5 最近使用
- 每次打开工具，记录 `id + 时间戳`，按**时间倒序**保留最近 **N 条（默认 8）**。
- 「最近使用」分组展示，**去重**（同一工具只出现一次，取最新时间）。
- 数据**本地持久化**；提供「清空最近使用」入口。
- 无记录时不显示该分组（或显示温和空态提示）。

### 4.6 工具详情或跳转入口
- 点击卡片 → 按配置的 `url` 跳转；默认**新标签页打开**（`target="_blank"` + `rel="noopener noreferrer"`），可通过配置改为当前页。
- 支持**站内跳转**（相对路径，如 `/business?section=stats`）与**站外链接**（完整 URL）两种形态。
- 工具可配置 `status`：`active`（可用）/ `maintenance`（维护中）/ `coming`（即将上线）。非 `active` 时**禁止跳转**，卡片显示对应状态徽标与置灰样式，并在 `title` 中说明。
- 卡片提供 `aria-label`，说明「打开 <名称>」及状态，便于读屏与键盘操作。

### 4.7 空状态与异常状态
| 场景 | 表现 |
|------|------|
| 搜索/筛选无结果 | 居中友好提示：说明未找到，展示当前关键字，提供「清空条件」按钮 |
| 无任何工具（配置为空） | 提示工具箱为空，引导维护者补充配置 |
| 无收藏 | 「常用工具」区显示引导文案（如「点击卡片右上角 ☆ 收藏常用工具」） |
| 无最近使用 | 「最近使用」区显示温和提示 |
| 工具维护中 / 即将上线 | 卡片置灰 + 状态徽标 + 不可点击 + 说明文案 |
| 本地存储不可用（隐私模式等） | 收藏/最近使用降级为「仅本次会话生效」，不报错、不阻断使用 |

### 4.8 后续工具的扩展方式（关键约束）
- **新增一个工具 = 在工具配置中追加一条元数据对象**，**不修改任何页面/组件逻辑**。
- 分类如需新增，同样在分类配置中追加一条。
- 配置形态：静态 TS 配置模块（后续可平滑切换为接口下发，字段契约不变）。
- 因此：所有展示、筛选、搜索、收藏逻辑必须是**对配置的通用处理**，禁止针对特定工具写分支。

## 五、非功能需求

### 5.1 首屏加载
- 路由**懒加载**（与 `/workbench`、`/business` 等一致），工具箱代码不进入导航站首屏包。
- 工具配置为**静态内联**，首屏**无额外网络请求**。
- 不引入重型依赖（不引图表库等）；图标优先复用项目 `Icon` 组件或 emoji/字符，避免额外资源下载。
- 目标：进入工具箱后内容**同屏渲染**，无骨架屏闪烁（数据量小，直接渲染）。

### 5.2 响应式适配
- **移动优先**，沿用项目既有断点约定：`≤359px` 超小屏 / `≥360px` 手机基线 / `≥768px` 平板 / `≥1200px` 桌面封顶。
- 卡片网格使用 `repeat(auto-fill, minmax(...))` 自适应降列；超小屏强制单列，避免溢出。
- 触控目标 ≥ 44px；卡片在移动端保证可点区域充足。
- 搜索框与分类栏在窄屏下换行/横向滚动，不挤压卡片。
- 支持**横竖屏**与**安全区**（`viewport-fit=cover` 已在项目 `index.html` 配置）。

### 5.3 无障碍（a11y）
- 语义化标签：`<main>` / `<section>` / `<nav>` / `<button>`，卡片用 `<a>` 或 `<button>`（按是否跳转选择）。
- 所有可交互元素可 **Tab 聚焦**，焦点样式沿用项目 `*:focus-visible`（主色 2px 描边 + offset）。
- 图片/图标提供 `aria-hidden` 或 `aria-label`；工具名称、描述可被读屏正确朗读。
- 搜索框带 `<label>` 或 `aria-label`；分类筛选使用 `aria-pressed` 表达选中态。
- 收藏按钮带 `aria-label`（「收藏 X」/「取消收藏 X」）与 `aria-pressed`。
- 尊重 `prefers-reduced-motion`：关闭过渡与位移动画（项目 `style.css` 已全局处理，组件不覆盖）。
- 文字对比度满足 WCAG AA（正文 ≥4.5:1）；状态徽标不**仅**用颜色区分，需同时有文字。

### 5.4 命名与目录规范
| 对象 | 规范 | 示例 |
|------|------|------|
| 路由路径 | 小写短横线 | `/toolbox` |
| 路由 name | 小驼峰 | `toolbox` |
| 视图组件 | `XxxView.vue`（放 `src/views/`） | `ToolboxView.vue` |
| 子组件 | `ToolboxXxx.vue`（放 `src/components/toolbox/`） | `ToolboxCard.vue` |
| 纯逻辑 | `xxxCore.ts`（放 `src/composables/`，零 Vue 依赖） | `toolboxCore.ts` |
| 工具配置 | `src/config/toolbox.ts` | 工具与分类元数据 |
| testid 前缀 | `tb-` | `tb-search`、`tb-card-<id>`、`tb-fav-<id>` |
| CSS 类名 | `tb-` 前缀（scoped） | `.tb-grid`、`.tb-card` |
| 持久化 key | 统一前缀 | `easy-web-tab:toolbox` |

## 六、范围边界（本期不做）

- 不做工具内容的「内嵌运行」（iframe 嵌入第三方页面）——本期仅做**入口聚合与跳转**。
- 不做服务端下发 / 后台管理界面——配置走代码内静态配置。
- 不做复杂的工具类实现（计算器、转换器等）——后续以「工具配置 + 独立页面」方式增量接入。
- 不做跨设备同步——收藏与最近使用仅本地持久化（云同步沿用项目既有 `settings` 信封时再评估）。
