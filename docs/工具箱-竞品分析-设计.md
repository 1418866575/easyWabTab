# 工具箱竞品分析 · 详细设计

> 配套文档：`docs/工具箱-竞品分析-需求.md`
> 目标：把「待新增 ~61 项 + 增强 9 项」落地为可实施的工程方案，全部复用现有工具箱架构。

---

## 1. 设计原则

1. **零侵入、注册式复用**：现有 `src/toolbox/` 已是「目录即工具」架构——新增工具 = 在 `tools/<id>/` 下新建 `index.ts`（元数据）+ `<Name>Tool.vue`（组件），列表/搜索/收藏/最近使用**自动生效**，无需改 registry/view。本设计不改动该机制。
2. **纯前端、本地处理、零上传**：与 FireOA、word.appinn 一致（也是本网站卖点）。涉及文件/文本均在浏览器内处理，禁止任何服务器回传。
3. **懒加载隔离重型依赖**：工具组件经 `() => import('./XxxTool.vue')` 懒加载；ffmpeg.wasm、pdf-lib、docx、mammoth 等重型库只在对应工具打开时按需加载，不进首屏包。
4. **分类扩展而非破坏**：在 `src/toolbox/config/categories.ts` 追加新分类（保持 `order` 顺序），不改动既有 11 个分类的语义。
5. **布局模板复用**：沿用 `ToolboxLayout`（T1 单栏 / T2 左右 / T3 上下 / T4 表单+结果卡 / T5 画布 / T6 列表表格），新工具按形态选模板，`tool-ui.css` 提供通用控件样式。

## 2. 模块划分（新增分类）

在现有 `dev/encode/data/text/image/color/time/calc/gen/effi/module/other` 基础上，**新增 4 个分类**，覆盖 FireOA 领先域：

| 新分类 id | 名称 | 图标 | 覆盖待新增 |
|-----------|------|------|-----------|
| `pdf` | PDF 工具 | 📄 | 合并/拆分/压缩/旋转/加密/删除页/盖章/转图/转文字/目录 |
| `cert` | 证书与安全 | 🔏 | RSA 密钥、X.509、PEM/JWK、CSR、ZIP 加密、盐值、API 密钥 |
| `doc` | 文档处理 | 📑 | DOCX 预览转 PDF、XMind 查看、元信息编辑、引用格式化、Markdown 转 PDF/Word、文档图片提取 |
| `media-edit` | 媒体编辑 | 🎬 | 视频剪辑/转 GIF/播放、音频剪辑/拼接/降噪/剪静音、GIF 优化 |
| `device` | 设备与测量 | 📐 | 相机拍照、指南针、量角器、屏幕标尺、噪音计、计时器、科学计算器 |

> 说明：证书/加密部分工具（AES/DES/HMAC/Bcrypt/Argon2）也属 `encode` 语义，可归入 `cert` 以便用户发现；网络/API 工具（WebSocket/cURL/API 测试/HTTP Header/CORS）归入既有 `dev`。

## 3. 工具注册机制（沿用）

每个新工具目录结构（以 `pdf-merge` 为例）：

```
src/toolbox/tools/pdf-merge/
├── index.ts              # 元数据 + 懒加载组件
└── PdfMergeTool.vue      # 工具 UI（用 tool-ui.css 通用样式）
```

`index.ts` 模板：

```ts
import type { ToolboxToolEntry } from '../../types'
const entry: ToolboxToolEntry = {
  meta: {
    id: 'pdf-merge',
    name: 'PDF 合并与重排',
    icon: '📄',
    description: '选择多个 PDF 按序合并或重排页面，纯本地处理',
    category: 'pdf',
    tags: ['pdf','合并','merge'],
    status: 'active',
    kind: 'internal',
    order: 10,
    modalSize: 'L',
    layout: 'T2',
    addedAt: '2026-10-xx'
  },
  component: () => import('./PdfMergeTool.vue')
}
export default entry
```

> 无需改 `registry.ts`（自动 `import.meta.glob` 扫描）、无需改 `ToolboxView.vue`、无需改搜索/收藏——**这是现有架构的核心收益**，本设计不重复造轮子。

## 4. 关键能力技术选型

| 能力 | 推荐库 / API | 加载方式 | 备注 |
|------|------------|----------|------|
| PDF 创建/合并/拆分/旋转/加密 | `pdf-lib` | 懒加载 | 纯 JS，体积小 |
| PDF 渲染→图片、文字提取 | `pdfjs-dist` | 懒加载 | worker 需配置 |
| PDF 压缩 | `pdf-lib`（重采样图片）+ 可选 ghostscript.wasm | 懒加载 | 纯前端压缩有限，标注预期 |
| 证书 X.509 解析/生成 | `@peculiar/x509` | 懒加载 | 标准合规 |
| RSA/CSR/PEM/DES/AES | `node-forge` | 懒加载 | Web Crypto 不支持 DES |
| Web Crypto（AES-GCM/HMAC/PBKDF2/RSA） | 浏览器原生 `crypto.subtle` | 内置 | 优先用原生 |
| Bcrypt / Argon2 | `bcrypt.js` / `argon2-browser`（WASM） | 懒加载 | 哈希增强 |
| JSON→代码模型 | 自写模板（无依赖） | 内置 | 字符串模板即可 |
| Markdown→PDF | `marked` + 浏览器 `window.print`（或 `jspdf`+`html2canvas`） | 懒加载 | 推荐 print 方案保真 |
| Markdown→Word | `docx`（生成 .docx） | 懒加载 | 或 `mammoth` 反向 |
| DOCX 预览 | `mammoth`（docx→html） | 懒加载 | 再走 print 转 PDF |
| 颜色对比度 WCAG | 自写公式（相对亮度） | 内置 | 无需库 |
| 配色提取 | `color-thief` | 懒加载 | canvas 取主色 |
| 图片尺寸/转 PDF | canvas + `jsPDF` | 内置/懒加载 | — |
| 文字⇄语音 | Web Speech API | 内置 | 原生，无需库 |
| JWT 生成 | `jsrsasign` 或 `node-forge` 签名 | 懒加载 | 补齐现有 jwt-decode |
| 视频/音频编辑 | `@ffmpeg/ffmpeg`（ffmpeg.wasm） | 懒加载 | 体积大（~30MB），仅媒体工具加载 |
| WebSocket 测试 | 原生 `WebSocket` | 内置 | — |
| cURL→代码 | 自写解析（正则） | 内置 | — |
| 文档图片提取 | `jszip`（docx/xlsx/pptx/epub 均为 zip） | 懒加载 | 抽取 media 目录 |
| 电子签名/截图标注 | canvas 2D | 内置 | — |
| 设备传感器 | `getUserMedia` / `DeviceOrientation` | 内置 | 需授权 |

## 5. 各新增模块 · 功能流程与实现要点

### 5.1 PDF 模块（P0/P1，分类 `pdf`）
- **功能流程**（通用）：选文件 → 解析（pdf-lib/pdfjs）→ 操作（合并/拆分/旋转/加密）→ 预览（pdfjs 缩略图）→ 导出（saveAs Blob）。
- **实现要点**：
  - 合并/重排/拆分/删除页：`pdf-lib` 的 `PDFDocument` 复制页面，拖拽排序用现有 `T2` 布局。
  - 旋转/加密：`pdf-lib` `setRotation` / `encrypt`。
  - 压缩：对图片型 PDF 重采样（`pdf-lib` 重写 XObject），明确告知「纯前端压缩弱于服务端」，预期管理。
  - 转图片/文字：`pdfjs-dist` 渲染 canvas / `getTextContent`。
  - 盖章/目录：在页面上叠加 PNG 或插入新页（进阶 P1）。
- **组件拆分**：`PdfMergeTool`、`PdfSplitTool`、`PdfCompressTool`、`PdfRotateTool`、`PdfEncryptTool`、`PdfExtractTool`（图/文字）等，共用一个 `usePdf` 组合式函数。

### 5.2 证书与安全模块（P0，分类 `cert`）
- **功能流程**：输入（粘贴 PEM/生成参数）→ 解析/生成（forge/peculiar.x509/Web Crypto）→ 结果展示（字段树）+ 复制/下载。
- **实现要点**：
  - RSA 密钥：`crypto.subtle.generateKey` 导出 PEM（用 forge 转换）或 forge 直接生成。
  - X.509 解析：`@peculiar/x509` 解析证书字段（Subject/Issuer/有效期/指纹）。
  - PEM/JWK/JWKS 互转：forge + 自写 JWK 编解码。
  - AES/DES/HMAC/Bcrypt/Argon2：forge（AES/DES）+ Web Crypto（HMAC）+ bcrypt.js/argon2-browser。
  - CSR：forge `pki.createCertificationRequest`。
  - ZIP 加密：forge `zip` + AES（或 `zip.js` 支持 AES）。
- **安全**：所有密钥在内存生成，绝不落盘/上传；提供「复制即清除」提示。

### 5.3 文档模块（P0/P1，分类 `doc`）
- **Markdown 转 PDF/Word / 引用格式化 / DOCX 预览 / XMind 查看 / 元信息编辑 / 文档图片提取**。
- **实现要点**：
  - 引用格式化：自写 GB-T 7714 / APA / MLA 模板（输入作者/题名/来源/年份 → 格式化串）。
  - 文档图片提取：`jszip` 解包 docx/xlsx/pptx/epub → 遍历 `word/media`、`ppt/media`、`META-INF` → 列出图片 → 打包下载（与 word.appinn 对齐）。
  - DOCX 预览：`mammoth.convertToHtml` → 渲染 → `window.print` 出 PDF。
  - XMind：`jszip` 解 `content.json`/`content.xml` → 递归大纲树。
  - 元信息编辑：docx/xlsx 用 `jszip` 改 `core.xml`；PDF 用 `pdf-lib` 改 metadata。

### 5.4 媒体编辑模块（P1，分类 `media-edit`）
- **功能流程**：选文件 → ffmpeg.wasm 加载（首启提示体积）→ 操作（剪辑/合并/降噪/转 GIF）→ 预览 → 导出。
- **实现要点**：
  - 统一 `useFfmpeg` 组合式函数，确保单例加载 `@ffmpeg/ffmpeg` + core。
  - 剪辑：`-ss/-to`；合并：`concat` demuxer；转 GIF：fps/scale 滤镜；降噪：`afftdn`/`anlmdn`。
  - **体积约束**：ffmpeg.wasm ~30MB，仅在媒体工具首次打开时加载，进度条提示；不纳入首屏。
  - 视频/音乐播放器：原生 `<video>/<audio>`，P2。

### 5.5 网络/API 模块（P1，归入 `dev`）
- WebSocket 测试：原生 `WebSocket` + 收发日志（T4 布局）。
- cURL→代码：正则解析 method/url/headers/body → 生成 fetch/axios/Python requests 片段。
- API 测试：fetch 封装 UI（method/url/headers/body/响应预览）。
- HTTP Header 解析、CORS 检查：纯前端解析；SSL 在线检查需联网 → 标 P2 可选。

### 5.6 设备与测量模块（P1，分类 `device`）
- 相机拍照：`getUserMedia` → canvas → PNG 下载。
- 指南针/量角器/屏幕标尺：DeviceOrientation（需授权）+ canvas 量角；屏幕标尺用 DOM 像素 + DPR 换算。
- 噪音计：`getUserMedia`(audio) → AnalyserNode → dB。
- 计时器/科学计算器：setInterval + `mathjs`（或自写安全 eval）。

### 5.7 增强现有工具（P0，改动已有 `index.ts` + 组件）
| 工具 | 改动 |
|------|------|
| 二维码生成器 | 组件加「多行批量 + ZIP」逻辑 |
| JSON/YAML/TOML 互转 | 组件加 INI 互转、JSON→Excel 导出 |
| Hash 生成器 | 加 Bcrypt/Argon2/HMAC 选项 |
| JWT 解析与验证 | 新增「生成」Tab（forge/jsrsasign 签名） |
| 图片压缩与格式转换 | 加尺寸调整、转 PDF、主色提取 |
| 颜色转换与取色器 | 加 WCAG 对比度检查子面板 |
| 密码生成器 | 加实时强度检测（zxcvbn 或自写规则） |
| Markdown 编辑预览 | 加导出 PDF（print）/Word（docx）按钮 |

## 7. 实施分期路线图

- **第一期（P0，约 25 项，优先级最高）**：PDF 基础套件(6) + 证书安全(8) + JSON→代码(1) + Markdown 转 PDF/Word(1) + 引用格式化(1) + 图片尺寸/转PDF/配色提取(3) + WCAG 对比度(1) + 科学计算器/计时器(2) + 电子签名(1) + 文字⇄语音(2) + JWT 生成(1) + 截图标注/特殊字符转义/HTML⇄MD(3)。
  - 预期：补齐「PDF + 安全 + 文档导出 + 通用刚需」，直接对标 FireOA 最被感知的差距。
- **第二期（P1，约 30 项）**：媒体编辑(9) + 网络/API(5) + DOCX/XMind/元信息(3) + PDF 进阶(3) + 图片进阶(4) + CSR/密码强度(2) + 字幕/印章/合同/数据提取(5) + 测量设备(6) + 文档图片提取(1)。
- **第三期（P2，可选/探索）**：长截图、SSL/AASA 在线检查、CSV 可视化、音乐/视频播放器、Golang Map→JSON。

## 8. 风险与约束

| 风险 | 说明 | 缓解 |
|------|------|------|
| ffmpeg.wasm 体积 | ~30MB，首启慢 | 仅媒体工具懒加载 + 进度提示；可改用浏览器原生 `MediaRecorder` 做轻量转码 |
| 纯前端 PDF 压缩弱 | 无 ghostscript | 明确预期；图片重采样为主 |
| Web Speech / 传感器兼容性 | 语音识别、DeviceOrientation 在桌面/部分浏览器不支持 | 特性检测 + 降级提示 |
| 重型库拖慢单工具首开 | pdfjs/forge/docx 等 | 均走 `import()` 懒加载，且只在该工具打开时加载 |
| 维护成本（61 项） | 工具数量翻倍 | 严格统一 `index.ts` 模板 + 组合式函数复用，避免各写一套 |
| 类型检查 / 构建 | 现有 master 有预存类型噪声 | 每期增量后按项目约定跑 `vue-tsc -b` + `vite build` 校验 |

## 9. 验收口径

- 每期交付：所有新增工具在 `/toolbox` 可被搜索、可被收藏、可记入最近使用。
- 每个新工具：纯前端零上传（代码审查确认无 fetch 到第三方）。
- 每期结束：跑完整构建（`generate-preset-icons` → `vue-tsc -b` → `vite build`）零类型错误。
- 增强项：现有工具增强后不破坏原功能，回归验证。
