## 二、高优先级（P0）—— 建议首批解决

### P0-1 安全区全面失效：底部操作区被系统条压住

- **问题描述**：`index.html` 的 viewport 缺少 `viewport-fit=cover`，导致代码中约 8 处 `env(safe-area-inset-bottom)` 恒等于 0；同时弹框全屏化规则只设了 `height:100%`，未补安全区内边距。
- **影响范围**：**全部全面屏 iPhone 及部分安卓手势条机型**，涉及工作台/学生台底部 Tab Bar、约 24 个 el-dialog + 12 个手写弹框。表现为"保存/取消"按钮被 Home 指示条压住、点不到。
- **预期改进效果**：补上属性与内边距后，底部可操作区域完全露出，误触与"按钮点不动"的投诉基本消失。改动量极小，是投入产出比最高的一项。

### P0-2 遮罩点击关闭失效：全屏弹框只能靠小叉

- **问题描述**：移动端全屏化把遮罩 `padding` 强制为 0、卡片 `height:100%`，遮罩没有任何裸露区域，`@click.self` 与 Element Plus 的 `close-on-click-modal` 全部落空。
- **影响范围**：至少 4 个组件确认受影响（备份管理、站点弹框、帮助弹框、设置弹框），并波及所有走该兜底规则的弹框。
- **预期改进效果**：恢复"点空白关闭"这一移动端最基础的直觉操作，降低全屏弹框的压迫感与退出成本。

### P0-3 首屏加载过重：打开首页即下载全部模块

- **问题描述**：4 个路由 View 全部静态导入、零懒加载；构建产物为 1.85MB 单 chunk（gzip 594KB）+ 705KB 单文件 CSS 全量阻塞渲染；`dist/index.html` 还有 29 个 `modulepreload` 在首屏并发抢占带宽。
- **影响范围**：**所有移动端首次访问**，弱网/中低端机尤甚，直接体现为首屏白屏时间长。
- **预期改进效果**：路由级懒加载 + 手动分包 + 精简预载后，首屏只需下载导航站所需代码，白屏时间可数量级下降，且不影响后续模块使用。

### P0-4 移动端反而全量渲染：长列表是卡顿主因之一

- **问题描述**：首页移动端强制 `pageSize=99999` 全量渲染站点；工作台面板在移动端直接返回全量记录、分页器被隐藏；全局搜索结果也未设上限且每项带图片。
- **影响范围**：导航站首页、健康/记账/日记/学生等所有面板弹框、全局搜索。站点多时单页 DOM 可达数千节点。
- **预期改进效果**：改为分批渲染/虚拟滚动/触底加载后，滚动帧率与内存占用显著改善，且与"移动端不分页"的初衷（减少操作步骤）不冲突。

### P0-5 图标缓存同步解析 + 外域图标逐卡请求

- **问题描述**：图标缓存每次调用都同步 `JSON.parse` 整份 base64 缓存（可达 MB 级），每张卡片渲染都触发；同时每张站点卡各自请求外域 favicon 服务，无并发控制、无失败兜底。
- **影响范围**：导航站首页每次渲染、每次滚动重绘；外网不可达时还会拖慢整页。
- **预期改进效果**：内存级缓存 + 批量/懒加载 + 失败快速降级占位图后，首页渲染阻塞消除，弱网下不再被图标请求拖累。

### P0-6 iOS 视口高度陷阱：弹框底部溢出可视区

- **问题描述**：多处弹框使用 `90vh` 或 `calc(100vh - 40px)`，iOS Safari 中 `100vh` 取大视口值，地址栏/工具条展开时底部内容落在可视区之外。
- **影响范围**：健康、日记、设置等弹框，表现为底部分页器与关闭按钮点不到——与 P0-1 叠加后问题更明显。
- **预期改进效果**：改用动态视口单位或小脚本实测高度后，弹框底部元素始终可达。

### P0-7 原生 confirm/alert 泛滥：阻塞线程、不跟主题

- **问题描述**：约 50 处直接使用原生 `confirm`/`alert`，会阻塞主线程、不跟随暗色主题、部分 WebView 中被静默拦截，且与项目自有的 Toast 提示风格割裂。
- **影响范围**：首页、备份管理、图标管理等模块的删除/覆盖确认与结果反馈。
- **预期改进效果**：统一为自有的确认弹框与 Toast 后，视觉一致性、暗色模式完整度、反馈可信度同步提升。

### P0-8 状态丢失：返回即重置

- **问题描述**：路由未定义 `scrollBehavior`；`App.vue` 用 `:key="$route.path"` 强制重建组件树；工作台当前面板 `activeSection` 只是组件内局部状态，未持久化也未写入 URL。
- **影响范围**：导航站↔工作台互跳、工作台内部面板切换。表现为滚动位置归零、分页/筛选条件丢失、回来必回落首页面板。
- **预期改进效果**：补滚动恢复 + 面板状态写入 URL query 后，跨页返回体验符合移动端直觉，也便于分享与刷新保持。

### P0-9 断点不统一：767px 与 768px 并存

- **问题描述**：移动端兜底规则用 767px，而记录/视图/逻辑判断用 768px，导致 768px 宽度（iPad mini 竖屏、部分安卓平板）呈"半移动态"——布局已切移动、但分页未精简、卡片未双列。
- **影响范围**：首页、三个工作台、学生台在 768px 附近的设备。
- **预期改进效果**：统一断点令牌后消除中间态，规则可预期、后续维护不再踩坑。

### P0-10 弹框卡片高度规则失效：字段被裁切

- **问题描述**：`records.css` 中 `.ewt-card { height:auto }` 是死规则，被组件内同名 scoped 选择器压过，360px 两列下仍锁 156px 且 `overflow:hidden`，第 4 行字段被裁掉。
- **影响范围**：健康模块记录卡片（运动/饮食/睡眠/体重）。
- **预期改进效果**：修正特异性后卡片内容完整显示，不再出现"信息被切一半"。

### P0-11 背景滚动穿透与橡皮筋

- **问题描述**：弹框打开后无背景滚动锁定，全屏容器普遍缺 `overscroll-behavior:contain`（仅少数几处有）。
- **影响范围**：移动端所有弹框与抽屉，滑到尽头会带动背景一起滚动。
- **预期改进效果**：滚动被正确 containment 后，弹框内滑动手感干净，不再"带动整页"。
