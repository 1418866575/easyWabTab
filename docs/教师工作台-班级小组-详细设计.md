# 教师工作台 · 班级小组 —— 详细设计（v1）

> 配套需求文档：`docs/教师工作台-班级小组-需求.md`
> 设计原则（沿用 AGENTS.md 教师约束）：**store 薄委托 + `teacherCore.ts` 纯函数 + `useIdb` 持久化**；组件/视图禁止内联重算，所有分组算法、归一化、统计一律走 core。

## 1. 数据模型

### 1.1 现有基础（已确认，勿改）
- `Student`（`types/teacher.ts:69-82`）：`id`（稳定主键）/ `no`（学号）/ `name` / `gender:'男'|'女'` / `boarding:boolean` / `post` / `special` / `health` / `address`。**无成绩字段**。
- 成绩在 `exams[]`（`TeacherExams`），按学生聚合平均分需从 exams 计算。
- `ClassBucket`（`types/teacher.ts:197-216`）：当前含 `students/parents/exams/papers/seats/duty/committee/timetable/growth/random/leaves/homeworks/talks`。

### 1.2 新增类型（`types/teacher.ts`）

```ts
/** 分组策略模式 */
export type GroupMode =
  | 'random'      // 纯随机
  | 'gender'      // 按性别（配合 genderSplit 各自独立）
  | 'score_homo'  // 按成绩同质（水平相当同组）
  | 'score_hetero'// 按成绩异质（按成绩蛇形，高低均衡）
  | 'order'       // 按学号顺序（切块 / 蛇形）
  | 'hetero'      // 异质均衡（性别 + 成绩综合）
  | 'boarding'    // 按住校/走读分桶

/** 人数不能整除时的余数处理 */
export type RemainderMode = 'rotate' | 'min' | 'random'
// rotate=轮转补位（每组轮流+1）；min=多余的人进人数最少组；random=随机补位

export interface GroupingStrategy {
  mode: GroupMode
  /** 二选一：指定组数 */
  groupCount?: number
  /** 二选一：每组人数（优先级低于 groupCount，UI 二选一） */
  perGroup?: number
  genderSplit?: boolean          // 男女各自独立分组（gender/hetero 时生效）
  remainder?: RemainderMode       // 默认 'rotate'
  lockTogether?: string[][]      // 必须同组的 studentId 组合
  separate?: string[][]          // 不能同组的 studentId 组合
}

export type GroupRole = '组长' | '记录员' | '汇报人' | string

export interface GroupMember {
  studentId: string
  role?: GroupRole
}

export interface StudentGroup {
  id: string
  name: string
  type: 'fixed' | 'temp'         // 固定 / 临时
  description?: string
  members: GroupMember[]         // 成员（只存 studentId）
  createdAt: string
  updatedAt: string
  fromSnapshot?: string          // 若由快照应用而来，记快照 id
}

/** 一次分组结果（用于预览/保存） */
export interface GroupingResult {
  groupName: string
  memberIds: string[]
}

/** 分组快照（保存某次分组结果，日后复用） */
export interface GroupingSnapshot {
  id: string
  name: string
  createdAt: string
  strategy?: GroupingStrategy     // 生成该快照所用的策略（可空，手改后保存）
  results: GroupingResult[]
}

// ClassBucket 新增字段（在现有字段后追加，不破坏既有）：
// groups: StudentGroup[]
// snapshots: GroupingSnapshot[]
```

设计取舍：小组是**班级维度的集合**，用数组 `groups[]`（与 `leaves[]/exams[]` 一致）而非 `Record<id,…>`，便于整体筛选、双视图渲染、按时间排序。成员一律 `studentId`，展示时反查 `Student`（姓名/性别/学号/头像色），规避重名。

## 2. 核心分组算法（纯函数，放 `teacherCore.ts`）

```ts
/**
 * 给定学生列表与策略，返回分组结果。
 * 纯函数：不读 store、不改原数组，便于单测（与 businessCore 的 FIFO 纯函数同范式）。
 */
export function generateGroups(
  students: Student[],
  strategy: GroupingStrategy
): { results: GroupingResult[]; warns: string[] }
```

### 2.1 步骤
1. **校验与告警**：`groupCount` 或 `perGroup` 缺失/非法 → warns；`groupCount > students.length` → 退化为「每人一组（或余下空组）」并 warn；锁组与隔离直接冲突 → warn 且跳过该约束。
2. **应用锁组（lockTogether）**：把每组合的学生先绑成一个「种子组」，后续分配时整体移动（视作一个不可拆单元）。
3. **应用隔离（separate）**：标记互斥对，分配阶段禁止同组；若与锁组冲突 → 以锁组优先并 warn。
4. **分桶/排序**（按 mode）：
   - `random`：Fisher–Yates 洗牌。
   - `gender`：`genderSplit` 时按男/女分成两批各自独立走后续分配；否则整体按性别交替（男女交错）入组以实现均衡。
   - `score_homo`：聚合 `exams` 平均分升序，顺序切块（水平相当同组）。
   - `score_hetero`：按平均分降序后**蛇形**入组（高低均衡）。
   - `order`：按 `no`（学号）升序，切块或蛇形（策略参数 `remainder` 之外的「切块/蛇形」子选项，可在 UI 简化为蛇形避免抱团）。
   - `hetero`：先按性别分成两半，再各自按成绩蛇形，最后两半结果交叉合并（综合均衡）。
   - `boarding`：按 `boarding` 分住校/走读两桶，各自独立分配（或 `genderSplit` 类似）。
5. **分配入 N 组**：`N = groupCount ?? ceil(len / perGroup)`。
   - 普通：轮流把候选序列塞入 `groups[i % N]`。
   - 种子组（锁组）：作为一个整体放入当前最空且不与隔离冲突的组。
6. **余数处理（remainder）**：当 `len % N != 0`：
   - `rotate`：多余的人按组序轮流各 +1；
   - `min`：多余的进当前人数最少组；
   - `random`：随机挑组补位。
7. **输出**：`GroupingResult[]`（组名默认「第1组…第N组」或「A组…」，可在 UI 改），附 `warns`。

### 2.2 成绩聚合（高级策略依赖）
- 新增纯函数 `avgScoreByStudent(exams: Exam[]): Record<studentId, number>`，从 `bucket.exams` 算每生平均分。
- `score_*` / `hetero` 策略在无 exams 数据时：`warns.push('本班暂无成绩数据，已按学号随机替代')` 并降级为 `random`，UI 上该策略置灰提示。

## 4. UI 组件设计

### 4.1 `TeacherGroups.vue`（主页面，对齐 `TeacherHomework/Talks` 范式）
- **顶部统计卡**（`TeacherStatCard`）：组数 / 固定组数 / 临时组数 / 总人数（去重）。
- **工具栏**（`.ewt-table-toolbar .is-split`）：左=搜索框 + 类型筛选（全部/固定/临时）；右=「新建小组」「随机分组」「快照」「视图切换」「导出」。
- **双视图**（`useViewMode` + `usePageSize('teacherGroups')` + `.ewt-pager`）：
  - 列表（`.ewt-table`）：组名 | 类型标签（固定蓝/临时灰）| 人数 | 成员 chip 行 | 操作列（`.ewt-op-col`：编辑/复制为临时/导出/删除）。
  - 卡片（`.ewt-card-grid`）：每组一张卡，组名 + 类型 + 人数 + `tw-chip` 成员网格（男蓝女粉）。

### 4.2 学生多选选择器（**本期必做的新组件** `TeacherStudentPicker.vue`）
- 现状：学生列表无勾选能力（调研确认），分组必须新做选择器。
- 实现：`el-table` + `type="selection"` 来源 `sortedStudents(store.bucket.students)`；已选区用 `tw-chip` 展示（可点 × 移除）；按 `gender` 着色；支持搜索过滤；返回 `studentId[]`。
- 复用点：点名(random)、值日(duty)、作业、谈话等未来凡需「选学生」都可复用此组件。

### 4.3 新建/编辑小组弹框（`.ewt-dialog-footer`）
- 字段：组名（必填）、类型（固定/临时 单选）、描述、成员（嵌入 `TeacherStudentPicker`）、角色分配（可选，选中的成员里指定组长等）。
- 校验：组名必填；至少 1 名成员；类型必选。

### 4.4 随机分组对话框
- 策略选择（mode 单选，含图标说明）；参数区=「组数 / 每组人数」切换输入；约束区=「锁定同组」「隔离」各一个多选（调起 `TeacherStudentPicker`）；余数策略单选；「按性别各自分组」开关（gender/hetero 时可用）。
- 右侧实时预览 `generateGroups` 结果（各组名单 + 人数），展示 `warns`（如无解/降级）。
- 底部：「保存为临时组」（把 results 落成 N 个 `StudentGroup`，type=temp）/「存为快照」/「取消」。

### 4.5 快照页（复用双视图）
- 列表/卡片展示 `snapshots`；操作：应用为临时组（applySnapshot → 生成 temp 组）、重命名、删除。

### 4.6 导出/打印
- 导出：`groups` 或某个快照 → Markdown（每组：`## 组名` + 有序名单含姓名/性别）；复制到剪贴板或下载 `.md`/`.txt`。
- 打印：分组结果区域加 `tw-no-print` 工具条，利用 `teacher.css` 的 `@media print` 隐藏侧栏/顶栏。

## 5. 图标
- `src/components/iconPaths.ts` 新增 `account-multiple`（群组）路径；若无合适现成图标再补。导航 `TEACHER_PAGES` 的 icon 指向它。

## 6. 级联与一致性
- `removeStudentCascade`（teacherCore）扩展：删除学生时清 `groups[].members` 与 `snapshots[].results[].memberIds` 的该 `studentId`，与 duty/committee 同级处理。
- 成员反查：展示时 `store.bucket.students.find(s => s.id === memberId)`，找不到（已删）则显示「（已移除）」占位，不报错。

## 7. 风险与边界
| 风险 | 处理 |
|---|---|
| 学生列表无多选 | 必做 `TeacherStudentPicker`，本期最大新增点 |
| 成绩分组无数据 | 降级 random + warn，UI 置灰 |
| 锁组/隔离冲突 | 锁组优先 + warn，不静默失败 |
| 删除学生留脏引用 | `removeStudentCascade` 级联 |
| 成员重名 | 全程 `studentId`，展示反查 |
| 移动端 | ≤768px 强制卡片视图（useViewMode） |
