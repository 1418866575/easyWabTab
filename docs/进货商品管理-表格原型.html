相比现状（卡片列表 + 每项一行配置子行）的变化

  • 一行一个产品，字段横向成列：产品名称 / 关联商品 / 单位 / 单价 / 商品数量 / 商品单价（派生）/ 操作；当前「主行 + 5 个配置项子行」的折叠结构取消。
  • 单元格内直接编辑（输入框默认无边框、hover/focus 才显形），失焦或 Enter 即保存 —— 与现在的改名交互一致。
  • 商品单价为派生只读列（单价 ÷ 商品数量），灰底标签展示，改单价/数量时实时刷新。
  • 新增行贴在表格底部并与列宽对齐，输入即预览商品单价，回车直接添加。
  • 内置产品（摊位费）行：删除按钮置灰 + 锁标；其余行可删。
  • 窄屏（≤768px）表格转「标签 + 值」卡片，字段名用 td::before 呈现，不再横向滚动。
