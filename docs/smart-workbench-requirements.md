# 智能工作台（Smart Workbench）需求说明

> 项目：easy-web-tab · 新增一级模块「智能工作台」
> 版本：v1.0（首版） · 文档状态：已确认，作为实现依据
> 一句话定位：**把散落在各处、反复重写的 AI 技能与提示词，沉淀成可检索、可复用、可搬运的个人资产库。**

---

## 1. 背景与目标

### 1.1 问题

在与 AI 协作的日常里，有两样东西会反复沉淀、又最容易丢失：

| 痛点 | 具体表现 |
|---|---|
| **提示词散落** | 写在聊天窗口、记事本、飞书文档里，用的时候靠翻记录；同一条提示词反复重写 |
| **技能无法复用** | 一套稳定的工作流（如"周报生成""代码评审"）每次都要重新描述背景、步骤、输出格式 |
| **没有版本与沉淀** | 改坏了没有回退；哪条最好用没有依据；换设备就全没了 |
| **难以分享** | 想把一条好用的技能给别人，只能复制一坨文本，格式、分类、变量说明全丢 |

### 1.2 目标

1. **一处沉淀**：技能与提示词统一入库，支持分类 / 标签 / 全文检索。
2. **开箱即用**：提示词支持模板变量，填表即生成可粘贴的最终文本。
3. **可搬运**：单个或批量导出为 `.json` / `.md`，他人导入即可还原（含分类与标签）。
4. **越用越准**：记录使用次数与最近使用时间，排序与统计反映真实使用习惯。

### 1.3 非目标（首版不做）

- 不接入任何大模型 API，不代用户调用模型（纯本地资产库，无密钥、无网络依赖）。
- 不做多人协作 / 权限 / 评论。
- 不做技能"自动执行"，仅提供内容沉淀与一键复制。

---

## 2. 用户与场景

**主要用户**：本人（重度 AI 使用者），兼顾"想复用别人技能"的同事。

| 场景 | 用户故事 |
|---|---|
| S1 沉淀 | 作为使用者，我想把一段验证有效的提示词存下来并打好标签，以便下次 3 秒内找到 |
| S2 复用 | 作为使用者，我打开一条带变量的提示词，填几个空就能得到成品文本，而不是手动替换占位符 |
| S3 沉淀工作流 | 作为使用者，我想把"需求文档生成"这套固定步骤存为技能，下次直接照做 |
| S4 分享 | 作为使用者，我想把 3 条常用技能导出成一个文件发给同事 |
| S5 迁移 | 作为使用者，换电脑 / 重装后导入备份文件，资产完整恢复 |

## 3. 信息架构

```
智能工作台 /smart
├── 概览（Overview）        —— 统计卡：技能数 / 提示词数 / 分类分布 / 最近使用
├── 技能管理（Skills）       —— 列表 + 增删改查 + 导入导出 + 复制内容
└── 提示词管理（Prompts）    —— 列表 + 增删改查 + 导入导出 + 变量填充 + 收藏
```

与现有模块的关系：与「工作台 / 销售 / 学生 / 老师」平级的一级模块，路由 `/smart`，
由导航站首页入口进入，页面顶部提供返回导航站。

## 4. 数据模型

### 4.1 技能 SmartSkill

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | ✓ | `sk_<timestamp>_<rand>` |
| name | string | ✓ | 名称，≤60 字，库内唯一（同名拦截） |
| category | string | ✓ | 分类（用户自定义分类表，缺省「未分类」） |
| icon | string | | 图标（emoji 或图标键），缺省 🧩 |
| tags | string[] | | 标签，≤8 个，每个 ≤16 字 |
| version | string | | 版本号，缺省 `1.0.0` |
| author | string | | 作者/来源 |
| description | string | | 一句话说明，≤200 字（列表副标题） |
| content | string | ✓ | 技能正文（Markdown），≤20000 字 |
| usageCount | number | | 使用次数（复制/使用时 +1） |
| lastUsedAt | number \| null | | 最近使用时间戳 |
| isBuiltIn | boolean | | 内置示例（可删除，不参与"重置示例"以外的保护） |
| createdAt / updatedAt | number | ✓ | 创建 / 更新时间戳 |

### 4.2 提示词 SmartPrompt

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | ✓ | `pm_<timestamp>_<rand>` |
| title | string | ✓ | 标题，≤60 字，库内唯一 |
| category | string | ✓ | 分类，缺省「未分类」 |
| tags | string[] | | 标签 |
| model | string | | 建议模型（如 GPT-4o / Claude / 通用），仅标注不校验 |
| content | string | ✓ | 提示词正文，支持 `{{变量}}` 占位，≤20000 字 |
| variables | PromptVariable[] | | **由正文自动解析**，不手工维护（见 4.3） |
| isFavorite | boolean | | 收藏 |
| usageCount | number | | 使用次数 |
| lastUsedAt | number \| null | | 最近使用时间 |
| isBuiltIn | boolean | | 内置示例 |
| createdAt / updatedAt | number | ✓ | 时间戳 |

### 4.3 模板变量

- 语法：`{{变量名}}`，变量名允许中英文、数字、下划线，长度 1–32。
- **自动解析**：保存正文时自动提取 `variables`，顺序按首次出现去重；**不提供手工编辑**，避免与正文不一致。
- 变量对象：`{ name, desc?, defaultValue? }` —— `desc`/`defaultValue` 由用户在「变量填充」弹框内临时填写并记忆为该提示词的变量元信息（可选，留空不影响使用）。
- 填充：把 `{{name}}` 替换为输入值；未填变量**保留原占位符**并提示，不静默清空。

### 5.6 导入导出文件格式（FR-6，规范性）

**JSON 信封**（单条与集合包同构，`kind` 区分）：

```json
{
  "kind": "smart-skills",
  "version": 1,
  "exportedAt": 1759392000000,
  "items": [ { "...SmartSkill 完整对象" } ]
}
```

- `kind`：`smart-skills` / `smart-prompts`；与当前页不匹配时**拒绝导入**并提示。
- `version`：当前 `1`；`>1` 拒绝（「文件来自更新版本」），`<1` 或缺失按 1 兼容。
- `items`：必须为数组；逐条归一化，非法条目跳过并计入「跳过 K」，不整体失败。

**Markdown 单条**（仅技能，便于阅读与 git 托管）：

```markdown
---
kind: smart-skill
version: 1
name: 需求文档生成
category: 写作
tags: [产品, 文档]
---

正文……
```

导入时优先解析 YAML 头；无头时以文件名作为名称、正文为内容。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| **持久化** | 复用项目统一偏好层（`getPref/setPref`，落 IndexedDB）；写入 `markDirty()` 纳入云同步脏标记；纳入备份信封，随「备份/恢复」一起走 |
| **性能** | 单库 ≤500 条时列表筛选/搜索无感（纯函数 + computed）；不引入额外依赖 |
| **一致性** | 复用项目既有组件与规范：Element Plus 控件、CSS 变量、`html.dark` 暗色、44px 移动端触控、toast 单例、`showConfirm` 二次确认 |
| **可测性** | 归一化 / 过滤 / 变量解析 / 信封解析抽为**零 vue、零 pinia** 的纯函数，纳入 `node --experimental-strip-types` 测试 |
| **健壮性** | 存储不可用（隐私模式）降级为内存态并提示，不阻断页面；导入非法文件给出具体原因（非 JSON / kind 不符 / 版本过高 / 结构错） |
| **无障碍** | 按钮可键盘聚焦，图标按钮带 `title`/`aria-label`，弹框支持 Esc 关闭 |

## 7. 关键交互流程

### 7.1 提示词「变量填充 → 复制」

```
列表点击「使用」 → 弹框（左：变量表单 / 右：实时预览）
  → 填值 → 预览高亮已替换部分
  → 点「复制结果」 → 剪贴板写入 → usageCount+1、lastUsedAt=now → toast「已复制」
  → 未填变量保留 {{name}} 并顶部提示「N 个变量未填写」
```

### 7.2 技能导入

```
点「导入」 → 选文件（.json / .md）
  → 解析失败 → toast 具体原因，终止
  → 解析成功 → 预览弹框（新增 N / 更新 M / 跳过 K + 逐条名称清单）
  → 确认 → 落库 + markDirty → toast「导入完成：新增 N，更新 M」
```

### 7.3 删除

```
点「删除」 → showConfirm（含名称 + 后果说明） → 确认 → 落库 → toast「已删除」
```

## 8. 异常与边界

| 场景 | 处理 |
|---|---|
| 名称超长 / 空 | 提交时拦截，字段下方红字 + 首个错误 toast |
| 正文为空 | 拦截（技能与提示词正文均必填） |
| 同名 | 拒绝并指明已存在条目名称 |
| 导入文件非 JSON / 结构错 / kind 不符 / version 过高 | 终止并 toast 具体原因，不留半成品 |
| 导入条目 id 已存在 | 视为更新（按 updatedAt 新者胜） |
| 剪贴板不可用（非 HTTPS 旧浏览器） | 降级：选中文本 + toast 提示手动复制 |
| 超长正文（>20000 字） | 保存时截断并提示（避免单条撑爆存储） |
| 存储写入失败 | toast 提示「本地保存失败」，内存态仍可用 |

## 11. 术语

- **技能（Skill）**：一段可复用的 AI 工作流说明（背景 + 步骤 + 输出规范），以 Markdown 承载。
- **提示词（Prompt）**：可直接投喂给模型的文本模板，支持 `{{变量}}` 占位。
- **信封（Envelope）**：导入导出文件的外层结构（kind/version/exportedAt/items）。
