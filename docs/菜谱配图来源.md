## 三、AI 生成补图（25 张）

社区志愿算力、免费、生成结果无版权限制）文生图补齐。

- 生成参数：Stable Diffusion，512×512，k_euler，26–30 steps，cfg 7–8
- 统一风格锚点：中式家常菜 / 自然光 / 暖色调 / 陶瓷碗 / 45° 视角

## 维护约定

- 新增原文配图 → 直接放 `public/recipes/<id>.jpg`，`image` 字段留空（走默认推导）或显式写路径
- 新增授权图/生成图 → 必须在本文件登记来源；授权图还要写清 license 与作者
- 生成图必须目视核对后再入库，宁可保留 emoji 也不要用近似图凑数
